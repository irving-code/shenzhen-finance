# 严格排序损失消融技术方案

方案日期：2026-10-10。配套文件为[严格排序损失消融实验方案](严格排序损失消融实验方案.md)。本方案规定实验配置、程序接口、运行目录、训练顺序、恢复规则和验收条件。

## 一、协议身份

实验协议编号为 `20261010_严格排序损失消融`，采用四个排序损失权重和三个随机种子的完整矩阵：

```text
rank_weight ∈ {0.00, 0.15, 0.30, 0.50}
seed ∈ {42, 43, 44}
```

共 12 个独立训练运行。每个运行使用一个新的运行目录、一个新的模型初始化和一个固定的随机种子。`rank_weight=0.30` 的已有模型只作为历史参考，不作为本矩阵的唯一训练来源。

新建独立配置文件：

```text
模型训练/严格排序损失消融实验配置.json
```

配置至少包含以下字段：

| `protocol.candidate_count` | 4 |
| `protocol.seed_count` | 3 |

| `features.channel_count` | 37 |
| `ranking.weights` | `[0.0, 0.15, 0.3, 0.5]` |

| `dependence.enabled` | `false` |

| `selection.score_tolerance` | `1e-8` |

## 三、程序职责和新增接口

在现有单模型程序之外建立独立的消融运行入口，避免修改旧实验目录中的配置和结果。建议新增以下文件：

| 文件 | 职责 |
|---|---|
| `run_ranking_ablation.py` | 读取矩阵配置，按候选和随机种子顺序调度完整运行 |
| `ranking_ablation_experiment.py` | 校验矩阵配置、输入身份、候选权重和目录身份 |
| `aggregate_ranking_ablation.py` | 合并周期、候选、种子和留出评价结果，计算配对差值与置信区间 |
| `verify_ranking_ablation.py` | 核验每个运行的输入、训练状态、评分、恢复和最终交付文件 |

现有模型、输入读取器、排序损失函数和评分实现可以复用，但每次调用必须显式传入：

```text
run_id
rank_weight
seed
config_sha256
input_sha256
```

训练日志、检查点和评价文件的路径必须由 `run_id` 唯一确定，禁止不同候选或不同随机种子共用输出文件。

运行开始时读取并核对：

- `模型预处理/横截面扩展输入/20261008_横截面排序优化/数据交付清单.json`；

- 四个时间分区索引和交易日期表。

输入必须满足 `complete`、`data_verified=true` 和 `passed`。重新计算全部文件摘要，与配置快照逐项比较。原有 27 通道与新增 10 通道拼接顺序固定，输入张量形状固定为 `(batch, 20, 37)`。

每个运行必须使用相同的训练资格记录、同一验证资格记录和同一留出记录。不同排序权重之间的日期采样顺序必须相同；不同随机种子只改变该种子规定的随机状态，不能根据候选结果改变采样范围。

## 六、损失计算

每个批次计算：

```text
L_total = L_return + rank_weight × L_rank
```

其中：

```text
L_return = smooth_l1_loss(pred, target, beta=0.02)
```

同一交易日内的股票对计算全局排序损失：

```text
L_rank = mean(0.02 × softplus(
    −sign(y_i − y_j) × (p_i − p_j) / 0.02
))
```

只保留 `y_i != y_j` 的股票对，股票对按现有实现等权处理。有效股票对为空时返回保留计算图的零损失。`rank_weight=0.00` 时仍计算并记录 `L_rank`，但不把它加入总损失，以便核对四组训练输入和配对数量完全一致。

本实验必须关闭以下路径：

- 因子组替换和依赖惩罚前向计算；
- Top10% 与普通组边界排序损失；
- 额外的收益方向损失、交易成本损失或正则项；
- 根据 2024 年结果调整权重、周期或 alpha 的逻辑。

## 七、确定性训练和恢复

每个运行在 CUDA 初始化前设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`，固定 Python、NumPy、PyTorch CPU 和 CUDA 随机状态，开启确定性算法并关闭 cuDNN 自动性能搜索。每个周期使用同一 `SameDateBatchSampler` 规则，完整覆盖训练资格记录一次。

每 100 个优化步骤保存恢复检查点。检查点至少包含：

- 模型参数；
- AdamW 状态；
- 当前候选权重和随机种子；
- 当前周期、下一批次位置和已完成批次数；
- Python、NumPy、PyTorch CPU/CUDA 随机状态；
- 累计收益损失、排序损失和有效股票对数量；
- 配置摘要、输入摘要和程序摘要。

恢复前核对候选权重、随机种子、配置摘要、输入摘要、模型维度和代码摘要。任一摘要不一致时直接终止。恢复后的第一批输出应与未中断运行的对应批次保持规定容差内一致。

## 八、周期选择和留出评价

每个周期保存 2023 年完整验证预测，并对固定 `alpha=0.3` 计算平滑预测。早停监控 2023 年综合分，规则为：第 6 周期前继续训练；第 6 周期及以后连续 3 个周期未严格改善 `0.0001` 时停止；最多 12 个周期。

周期选择顺序固定为：

1. 2023 年综合分降序；
2. Rank IC 降序；
3. Top10% 年化超额收益降序；
4. 周期升序。

每个候选和种子的最终周期必须通过：

- 非有限值检查；
- 常数预测检查；
- 预测分辨率检查；
- 4096 与 2048 推理的逐日 Spearman 相关性检查；
- 两种批量的 Top10% 持仓重叠检查。

全部 12 个运行完成并锁定各自周期后，分别在 2024 年生成一次原始预测和一次 `alpha=0.3` 平滑预测。留出评价只读取已锁定检查点，不修改任何训练状态。

## 九、官方评分和本地评分一致性

2023 年候选评分使用主办方原版 `赛题五/evaluate.py`，输入临时目录包含：

```text
测试集_Y.csv
测试集_X.csv
候选预测.csv
```

本地评价程序按同一公式计算四个指标，并核对：

- 记录数量；
- 股票日期键；
- 预测排序；
- 涨停剔除规则；
- Top10% 计数规则；
- 换手率持仓集合；
- 综合分绝对差是否不超过 `1e-12`。

官方评分结果保存每个候选、种子、周期和 alpha 的逐项指标。测试集只用于覆盖核验，不在本实验中生成正式提交文件。

## 十、配对比较和统计文件

`aggregate_ranking_ablation.py` 生成以下文件：

| 文件 | 内容 |
|---|---|
| `comparison/验证周期指标.csv` | 每个候选、种子和周期的 2023 年指标 |
| `comparison/留出集指标.csv` | 每个候选和种子的 2024 年指标 |
| `comparison/A_vs_C_daily_delta.parquet` | 同一种子下 A 与 C 的逐日差值 |
| `comparison/跨种子摘要.csv` | 均值、中位数、标准差和通过状态 |
| `comparison/置信区间.json` | 五交易日分块配对重采样结果 |
| `comparison/官方评分核验.csv` | 官方程序与本地程序逐候选差异 |
| `comparison/完整性核验.json` | 运行矩阵和产物覆盖情况 |

逐日差值按 `trade_date` 与股票日期键合并，合并前检查重复键和缺失键。置信区间重采样固定随机种子 `20261010`，重采样次数为 10,000 次，块长度为连续五个交易日。统计结果同时保留原始日期指标，不能只保存聚合分数。

## 十一、验收条件

实验可以标记为 `complete`，需要同时满足：

1. 12 个候选运行均有完整配置快照和输入接入记录；
2. 每个运行完成规定的最少周期或按质量规则合法停止；
3. 每个运行的最终选择记录可由保存的周期指标独立重算；
4. A 与 C 的三种子配对比较文件完整；
5. 2023 年官方评分与本地评分在规定容差内一致；
6. 2024 年留出集评价未参与选择过程；
7. 所有预测键、日期范围和记录数量通过核验；
8. 恢复核验、双批量稳定性核验和最终产物摘要通过。

任一条件不满足时，实验状态为 `failed_verification`，报告保留失败位置和原始诊断文件，停止生成结论性排名。

## 十二、结果报告结构

最终报告按以下顺序写入：

1. 协议身份、输入摘要和运行矩阵；
2. 四个排序权重的训练与验证指标；
3. 各随机种子的周期选择结果；
4. 2024 年原始预测和平滑预测指标；
5. A 与 C 的逐日配对差值和跨种子置信区间；
6. B、C、D 的权重强度关系；
7. 官方评分与本地评分核验；
8. 质量检查、恢复检查和文件完整性；
9. 严格消融结论。

结论必须明确说明排序损失对 Rank IC、Top10% 收益、换手率和综合分的分别影响，并注明结论来自 2024 年历史留出集。任何未参与实验的外部测试标签不得写入结果。
