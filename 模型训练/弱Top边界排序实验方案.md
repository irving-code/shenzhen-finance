# 弱 Top 边界排序实验方案

## 1. 实验目标

验证较弱的 Top10% 与普通股票边界排序约束，能否在保持全体股票排序能力的同时改善官方综合分。

上一轮 `lambda_top=0.3` 时，Top 边界项与全局排序项的加权损失量级接近，新增排序约束过强。本轮只调整 Top 边界损失权重，保留 37 个因子、模型结构、数据划分和评价流程。

## 2. 实验分组

| 组别 | 含义 | Top 边界权重 | 是否重新训练 |
|---|---|---:|---|
| B0 | 既有 37 因子、全局排序损失、关闭依赖惩罚 | 0 | 复用已有检查点并重新整理 2023 年官方评分 |
| B2 | 弱 Top 边界约束 | 0.05 | 是 |
| B3 | 较弱 Top 边界约束 | 0.10 | 是 |

B0 使用既有无依赖惩罚实验的检查点。B2 和 B3 使用独立运行目录，不能写入 B0 或上一轮 B1 目录。

## 3. 固定数据划分

| 数据分区 | 时间范围 | 用途 |
|---|---|---|
| `train_fit` | 2018—2022 | 训练模型参数和 Top 标签 |
| `validation` | 2023 | 选择训练周期、平滑参数和候选配置 |
| `local_holdout` | 2024 | 对最终选定候选进行一次历史留出评价 |
| `competition_test` | 2025—2026 | 本轮不读取、不预测 |

不重新执行预处理，不重新划分时间，不使用测试集 X，不读取测试集 Y，不生成 `submission.csv`。

## 4. 固定模型和训练参数

| 项目 | 固定值 |
|---|---|
| 输入因子 | 37 个 |
| 模型 | 当前 LSTM-Transformer 回归模型 |
| 序列长度 | 20 个交易日 |
| 随机种子 | 42 |
| 训练批量 | 512 |
| 推理批量 | 4096 |
| 训练周期 | 8 个周期 |
| 全局排序损失权重 | 0.3 |
| 排序 `beta` | 0.02 |
| 排序 `tau` | 0.02 |
| 优化器 | AdamW |
| 学习率 | 0.0003 |
| 权重衰减 | 0.0001 |
| 梯度裁剪 | 1.0 |
| 因子依赖训练惩罚 | 关闭 |
| 训练设备 | RTX 4060 Laptop GPU |

本轮不改变因子数量、模型层数、序列长度、学习率、批量大小和随机种子。

## 5. Top10% 标签和损失

对训练集每个交易日构造有效股票集合：

```text
V_d = flag_limit_up == 0 且 y_ret_1d 非缺失
```

按照真实下一日收益 `y_ret_1d` 降序排列，取：

```text
top_count = max(len(V_d) // 10, 1)
```

前 `top_count` 条记录标记为 Top 组，其余记录标记为普通组。标签只在 2018—2022 年训练数据中构造，2023 年和 2024 年只用于评价。

B2 和 B3 使用：

\[
L_{total}=L_{return}+0.3L_{global-rank}+\lambda_{top}L_{Top-vs-rest}
\]

其中 `lambda_top` 分别为 0.05 和 0.10。`L_global-rank` 继续约束全体股票的连续排序，`L_Top-vs-rest` 只要求 Top 组预测分数高于普通组。因子依赖训练惩罚保持关闭。

边界损失使用同一交易日批次内的 Top×普通组交叉配对：

\[
L_{Top-vs-rest}=
\frac{1}{|T_d||R_d|}
\sum_{i\in T_d}\sum_{j\in R_d}
\tau\operatorname{softplus}\left(-\frac{s_i-s_j}{\tau}\right)
\]

模型仍只输出一个连续预测分数，推理时按分数降序选择前 10%。

## 6. 训练执行和目录

每个权重独立建立运行目录：

```text
模型训练/弱Top边界排序实验/
└── 20261010_weak_top_boundary_rank/
    ├── B2_lambda_top_0.05/
    └── B3_lambda_top_0.10/
```

每个目录保存配置快照、输入摘要、8 个周期训练统计、8 个检查点、损失分项、有效配对数、训练耗时和采样摘要。

每个周期必须满足：

- 完整覆盖 4,510,263 条训练资格记录；
- 包含 9,393 个同日批次；
- Top 边界有效配对数大于零；
- 损失、梯度和模型参数均为有限值；
- 检查点身份摘要可以通过核验。

## 7. 2023 年官方评分

对 B0、B2、B3 的每个周期生成原始预测，比较：

```text
alpha = 1.0、0.7、0.5、0.3
```

使用同一组 2023 年股票日期键建立临时评分目录：

```text
2023官方临时评分目录/
├── 测试集_Y.csv
├── 测试集_X.csv
└── 候选目录/epoch_XX/alpha_A/候选预测.csv
```

其中 `测试集_Y.csv` 保存 `ts_code`、`trade_date`、`y_ret_1d`，`测试集_X.csv` 保存 `ts_code`、`trade_date`、`flag_limit_up`。每个候选均调用主办方原版 `赛题五/evaluate.py`，不生成 `submission.csv`。

记录 Rank IC、年化 Top10% 超额收益、平均换手率、三项加权贡献和官方综合分：

```text
综合分 = 0.4 × Rank IC
       + 0.3 × 年化 Top10% 超额收益
       + 0.3 × (1 - 平均换手率)
```

## 8. 候选选择和核验

所有组统一按以下顺序选择：

1. 官方综合分降序；
2. Rank IC 均值降序；
3. 年化 Top10% 超额收益降序；
4. 训练周期升序；
5. alpha 降序。

候选必须通过非有限值、常数预测、每日有效标签数量、本地与官方评分一致性以及 4096/2048 推理批量稳定性检查。

## 9. 2024 年历史留出评价

根据 2023 年官方评分和稳定性结果，在 B0、B2、B3 中固定一个最终候选，只评价一次 2024 年历史留出集。记录 Rank IC、ICIR、正 IC 比例、年化超额收益、Top10% 年化绝对收益、平均换手率、三项贡献、综合分和质量核验。

如果 B0 继续获得最高 2023 年综合分，则复用已有 B0 的 2024 年历史留出结果，并在报告中记录复用来源。

## 10. 结果判断

- B2 或 B3 综合分超过 B0，且 Rank IC、年化超额收益和换手率没有明显牺牲，说明弱边界约束有继续价值；
- 只有换手率改善而 Rank IC 或年化超额收益下降，记录为指标权衡；
- 两个权重都低于 B0，停止当前 Top 边界路线；
- B2 优于 B3，说明更弱边界约束更适合当前模型；
- B3 优于 B2，说明边界项需要一定强度。

## 11. 产物和资源

每个新目录保存训练记录、检查点、2023 年官方评分比较表、候选选择文件、稳定性核验、2024 年评价或 B0 复用说明、结果报告和最终核验文件。既有实验、配置、预处理产物和检查点全部保留。

上一轮单个 8 周期训练约需 2 小时，B2 和 B3 顺序训练预计约需 4 小时，官方评分和历史留出评价预计另需 10—20 分钟。
