# 前 10% 边界排序参数调整技术方案

## 实验目标

验证 Top10% 边界排序损失是否能够提高 Top10% 年化超额收益和综合分，再调整边界损失、全局排序损失和 alpha 参数。

本实验使用 37 个因子、当前 LSTM-Transformer、现有预处理和既定时间划分。2025—2026 年测试集 X 暂不处理，不生成正式 `submission.csv`。

## 固定条件

| 参数 | 设置 |
|---|---:|
| 输入因子 | 37 |
| 序列长度 | 20 |
| 全局排序损失权重 | 0.3 |
| 因子依赖训练惩罚 | 0.0 |
| 随机种子 | 42 |
| 学习率 | 0.0003 |
| 权重衰减 | 0.0001 |
| 训练批量 | 512 |
| 推理批量 | 4096 |
| 排序损失 beta | 0.02 |
| 排序损失 tau | 0.02 |

训练数据使用 2018—2022 年，2023 年用于选择周期和 alpha，2024 年用于最终历史留出评价。

## 候选比较顺序

### 组件消融

| 组别 | 全局排序权重 | Top 边界权重 | 用途 |
|---|---:|---:|---|
| B0 | 0.3 | 0.0 | 当前无 Top 边界损失基线 |
| B1 | 0.3 | 0.3 | 验证新增 Top 边界损失 |

B0 优先复用已有无依赖惩罚检查点，B1 进行新训练。

B0 和 B1 使用相同随机种子、输入顺序、采样器和模型初始化规则。B1 的输入摘要、程序摘要和损失配置单独保存，保证组件消融只比较新增 Top 边界损失。

### Top 边界权重

只有 B1 相对 B0 有效后，才比较：

```text
lambda_top = 0.15、0.30、0.50
```

全局排序权重保持 0.3。

### 全局排序权重

确定 Top 边界权重后，再比较：

```text
lambda_global = 0.15、0.30、0.50
```

Top 边界权重保持上一轮的最佳值。

### 时间平滑参数

每个候选周期比较：

```text
alpha = 1.0、0.7、0.5、0.3
```

alpha 只影响预测后的时间平滑，不参与模型参数训练。

## Top10% 标签构造

对每个训练交易日，使用 `flag_limit_up == 0` 且 `y_ret_1d` 非缺失的记录构造有效集合。按照真实 `y_ret_1d` 降序排列，Top 组数量使用官方规则：

```text
top_count = max(有效股票数量 // 10, 1)
```

前 `top_count` 条记录标记为 Top 组，其余有效记录标记为普通组。缺少 `y_ret_1d` 的记录不参与 Top 边界损失。

Top 组标记按 `ts_code + trade_date` 生成训练专用标签表，再与同日训练批次合并。2023 年标签只用于官方评分，2024 年标签只用于固定配置的历史留出评价，测试集 X 不生成 Top 组训练标签。

## 损失函数

训练损失为：

\[
L_{total}=L_{return}+\lambda_{global}L_{global-rank}+\lambda_{top}L_{Top-vs-rest}+L_{dependence}
\]

本实验固定 `L_dependence=0`。

`L_Top-vs-rest` 对 Top 组与普通组进行成对排序，要求 Top 组预测分数整体高于普通组。Top 组内部和普通组内部的排序继续由现有全局排序损失处理。

同日批次中同时存在 Top 组和普通组时计算边界配对；缺少一类记录的批次将边界损失记为零，并记录有效边界配对数量。全局排序损失和边界排序损失分别按有效配对数量取平均，训练记录保存原始损失、有效配对数量和加权损失贡献。

新增边界损失的计算接口需要返回 `loss_top_boundary`、`top_pair_count`、`top_count` 和 `rest_count`。若一个训练周期的有效边界配对总数为零，立即终止该候选并记录配置错误。

## 评价流程

每个候选周期生成 2023 年原始预测，并对每个 alpha 生成平滑预测。每个候选目录包含：

```text
测试集_Y.csv
测试集_X.csv
候选预测.csv
```

三个文件使用相同的 `ts_code` 和 `trade_date`。评分前检查三个文件的行数、重复键、键集合、日期范围和有限数值。调用主办方原版 `赛题五/evaluate.py` 计算 Rank IC、Top10% 年化超额收益、平均换手率和综合分。预测文件使用 `候选预测.csv` 名称，不生成 `submission.csv`。

官方评分结果与本地统一评价结果逐项比较，差异超过现有容差时终止候选选择。

## 2023 年选择规则

候选按以下顺序选择：

1. 综合分降序；
2. Rank IC 均值降序；
3. Top10% 年化超额收益降序；
4. 训练周期升序；
5. alpha 降序。

候选必须通过非有限值、常数预测、每日有效标签、双批量推理稳定性和官方评分一致性检查。

候选选择记录还保存 `input_hash`、`source_hash`、`config_hash`、`seed`、`lambda_global`、`lambda_top`、`epoch` 和 `alpha`，确保评分结果可以追溯到具体模型检查点。

## 2024 年历史留出

2023 年确定 `lambda_global`、`lambda_top`、训练周期和 alpha 后，只评价一次 2024 年数据。记录 Rank IC、ICIR、Top10% 年化超额收益、平均换手率、综合分和月度指标。2024 年结果不回写候选选择过程。

## 产物目录

新实验独立保存于：

```text
模型训练/前10%边界排序实验/20261010_parameter_tuning/
```

目录包含配置快照、B0 基线、B1 实验、参数比较、2023 年评分、2024 年历史留出结果和模型结果评估报告。已有实验、配置、代码、检查点和预处理产物保持原样。

建议新增以下独立程序文件，避免改变旧实验入口：

- `top_boundary_rank_loss.py`：实现 Top/普通边界成对损失；
- `train_top_boundary_rank.py`：训练 B1 和后续权重候选；
- `evaluate_top_boundary_rank.py`：生成预测、alpha 平滑结果和评分文件；
- `coordinate_top_boundary_rank.py`：执行预检、训练、选模和历史留出评价；
- `前10%边界排序参数调整配置.json`：保存候选矩阵和固定条件。

## 运行控制

训练任务使用 RTX 4060 Laptop GPU 单任务顺序运行。B0 复用已有检查点，B1 和后续参数候选保存独立检查点。每个周期记录训练耗时、验证耗时、显存峰值、输入摘要和程序摘要，支持从最近检查点继续运行。

训练记录还要包含 `loss_return`、`loss_global_rank`、`loss_top_boundary`、`weighted_global_rank`、`weighted_top_boundary`、`global_pair_count` 和 `top_pair_count`，用于确认新增项确实参与反向传播且权重尺度符合配置。
