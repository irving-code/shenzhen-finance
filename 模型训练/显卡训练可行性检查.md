# 显卡训练可行性检查

## 检查结果

- 显卡：NVIDIA GeForce RTX 4060，显存约 8 GB；
- NVIDIA 驱动：595.79；
- 驱动报告的 CUDA 版本：13.2；
- 当前 PyTorch：`2.12.1+cpu`；
- `torch.version.cuda`：`None`；
- `torch.cuda.is_available()`：`False`；
- CUDA 设备数量：0。

## 结论

显卡硬件和驱动正常，当前训练环境具备使用显卡的硬件条件。当前 PyTorch 是 CPU 版本，因此训练脚本无法调用 CUDA。

本机没有可用的 CUDA 版 PyTorch 安装包缓存，访问 PyTorch CUDA 软件源时受到网络策略限制，暂时无法自动切换安装包。CPU 训练已暂停，原始数据、因子文件和预处理结果未修改。

## 切换条件

安装与 Python 版本匹配的 CUDA 版 PyTorch 后，确认以下结果即可切换训练设备：

```text
torch.version.cuda 不为 None
torch.cuda.is_available() 为 True
```

训练脚本已经支持 `--device cuda` 参数。
