# 第二步：综合分验证与换手率优化实验方案

## 1. 实验名称

LST-Transformer 基于比赛综合分的模型选择与换手率优化实验。

## 2. 实验目标

本实验用于回答两个问题：

1. 使用比赛综合分选择最佳训练周期，是否比只使用 Rank IC 选择模型更符合比赛目标；
2. 在综合分选择的基础上，预测分数平滑是否能够降低换手率并提高最终综合分。

第一个问题对应当前优化计划中的第二步。第二个问题用于继续验证降低换手率的方法。

### 2.1 当前必须修改

本轮先完成以下内容：

1. 以赛题提供的 `evaluate.py` 作为指标计算的主规则来源；
2. 保留 `evaluate.R` 作为最终结果的独立复核程序；
3. 将赛题评价逻辑接入验证集和本地留出集的预测数据表；
4. 修正 Rank IC、Top1 取样、换手率样本过滤和前一持仓集合重置规则；
5. 增加预测键、样本覆盖、预测值有限性和官方提交文件完整性检查；
6. 将每个训练周期的预测结果保存为 Parquet，复用赛题 `evaluate.py` 的指标逻辑；
7. 在每个训练周期计算完整比赛指标，并完成实验组 A 和实验组 B 的比较；
8. 使用验证集综合分完成实验组 B 的模型保存和早停判断；
9. 只有在模型和参数确定后，才生成最终 `submission.csv`。

### 2.2 后续计划修改

完成当前指标接入和实验组 A、B 核验后，再执行以下内容：

1. 实现实验组 C 的时间平滑；
2. 在验证集测试多个 `α`，选择综合分最高的平滑参数；
3. 固定实验组 B 的模型和最佳 `α`，评估本地留出集；
4. 将最终 Parquet 预测结果导出为完整 CSV，使用 Python 和 R 评价结果进行最终交叉核对；
5. 本方案完成后，再进入持有缓冲、时间稳定性损失、Pairwise Ranking Loss、滚动验证、
   因子窗口消融和模型融合实验。

## 3. 实验假设

### 3.1 综合分选择假设

当前模型按照验证集 Rank IC 选择最佳训练周期。实验改为按照验证集综合分选择模型。

预期观察以下变化：

- 最佳训练周期可能发生变化；
- 验证集换手率可能降低；
- 综合分能够更完整地反映模型的比赛表现。

### 3.2 预测平滑假设

对同一只股票相邻交易日的预测分数进行时间平滑，减少预测值的短期波动，可能降低 Top10% 股票组合的换手率。

平滑公式为：

```text
s_t = α × p_t + (1 - α) × s_(t-1)
```

其中：

- `p_t` 表示当天原始预测分数；
- `s_t` 表示当天平滑后的预测分数；
- `α` 表示当天预测值的权重。

## 4. 比赛综合分

综合分按照项目当前采用的比赛评分结构计算：

```text
综合分
= 日度 Rank IC 均值 × 0.4
+ Top10% 年化超额收益 × 0.3
+ (1 - 平均换手率) × 0.3
```

### 4.1 日度 Rank IC

对每个交易日单独计算预测值和真实收益的 Spearman 相关系数（基于排名的相关系数）。

计算规则：

- 删除 `y_ret_1d` 缺失的样本；
- 当天有效样本数少于 30 时跳过当天；
- 使用剩余样本的 `pred` 和 `y_ret_1d` 计算横截面 Spearman 秩相关系数；
- 不根据 `limit_up` 过滤 Rank IC 样本；
- 对所有有效交易日的 IC 求平均。

### 4.2 Top10% 年化超额收益

每天执行以下步骤：

1. 剔除涨停股票；
2. 剔除 `y_ret_1d` 缺失样本；
3. 当天有效股票数至少为 100；
4. 按照预测值从高到低排序；
5. 计算 `top_count = max(len(valid) // 10, 1)`，取前 `top_count` 只股票作为 Top1 组；
6. 计算 Top10% 股票平均收益减去全部有效股票平均收益；
7. 将所有交易日的平均超额收益乘以 252，得到年化超额收益。

这里的 `len(valid) // 10` 使用向下取整，保持与官方 Python 评测脚本一致。

### 4.3 平均换手率

每天只剔除 `flag_limit_up == 1` 的股票，按照预测值从高到低排序，取
`top_count = max(len(valid) // 10, 1)` 只股票组成 Top1 持仓集合。换手率不剔除
`y_ret_1d` 缺失样本，因为官方换手率只依赖预测值、股票代码和涨停标记。

当天有效股票数少于 100 时，跳过当天换手率计算，并将前一持仓集合重置为空；
下一个有效交易日不与该无效日期之前的持仓集合比较。其他有效交易日比较相邻的
持仓集合：

```text
换手率
= 1 - 两天持仓集合的交集数量 / 两天持仓集合的并集数量
```

例如：

```text
第 1 天：A、B、C、D
第 2 天：B、C、D、E
```

两天的交集数量为 3，并集数量为 5，因此：

```text
换手率 = 1 - 3 / 5 = 0.4
```

综合分使用：

```text
1 - 平均换手率
```

换手率计算必须使用与官方评测脚本相同的有效样本规则：

```python
valid = group[group['flag_limit_up'] == 0]
if len(valid) < 100:
    previous = None
    continue
```

## 7. 每个训练周期的操作

### 7.1 生成验证集预测

每轮训练完成后，使用当前模型生成验证集预测，形成以下字段：

```text
ts_code
trade_date
pred
y_ret_1d
limit_up
prediction_eligible
```

字段含义如下：

- `ts_code`：股票代码；
- `trade_date`：目标交易日；
- `pred`：模型预测值；
- `y_ret_1d`：下一交易日真实收益；
- `limit_up`：涨停标记。
- `prediction_eligible`：序列输入资格标记，用于数据追踪和完整性检查。

每轮预测优先保存为：

```text
验证集预测_epoch_XX.parquet
```

Parquet 评价表使用 `ts_code + trade_date` 对齐标签和涨停字段。训练过程不把每轮结果
转换成 CSV。

### 7.2 补充涨停信息

验证集涨停字段来自：

```text
模型预处理/步骤5_标准化处理/验证集_标准化.parquet
```

验证集序列索引来自：

```text
模型预处理/步骤6_序列构造/序列索引_validation.parquet
```

通过序列索引中的 `source_row_index` 找到标准化数据中对应行的 `limit_up`。

需要检查：

```text
预测行数 = 验证集合格序列数量
预测日期 = 序列索引中的 target_date
预测股票代码 = 序列索引中的 ts_code
```

模型训练和序列输入接口只读取：

```text
prediction_eligible == 1
```

比赛指标计算不能把 `prediction_eligible == 1` 作为统一的额外筛选条件，必须分别执行
官方规则：

| 指标 | 指标计算样本 |
|---|---|
| Rank IC | 删除 `y_ret_1d` 缺失样本；有效样本少于 30 时跳过当天；不筛选涨停标记 |
| Top10% 年化超额收益 | `flag_limit_up == 0` 且 `y_ret_1d` 非缺失；有效样本少于 100 时跳过当天 |
| 平均换手率 | `flag_limit_up == 0`；有效样本少于 100 时跳过当天并重置前一持仓集合 |

验证集和本地留出集的预测记录必须先与原始目标日记录按
`ts_code + trade_date` 对齐，再按上表计算指标。不得因为 `y_ret_1d` 缺失而从换手率
的持仓集合中删除股票。

官方测试集提交文件必须覆盖测试集中的每一个 `ts_code + trade_date` 记录。提交前必须
检查预测行数、股票代码集合、交易日期集合和键的唯一性；缺少任何测试记录时直接终止
提交流程。

提交前完整性检查为：

```text
提交行数 = 测试集_X 行数
提交键集合 = 测试集_X 的 ts_code + trade_date 键集合
提交键无重复
提交股票代码集合与测试集一致
提交交易日期集合与测试集一致
```

最终提交前才执行：

```text
Parquet 预测结果 → 完整 submission.csv → evaluate.py 正式评价 → evaluate.R 独立复核
```

## 9. 预测平滑规则（后续计划修改）

平滑过程按交易日期顺序进行，并且每只股票单独保存前一交易日的平滑分数。

例如某只股票连续三天的原始预测值为：

```text
第 1 天：0.80
第 2 天：0.20
第 3 天：0.70
```

当 `α = 0.5` 时：

```text
第 1 天平滑值 = 0.80
第 2 天平滑值 = 0.5×0.20 + 0.5×0.80 = 0.50
第 3 天平滑值 = 0.5×0.70 + 0.5×0.50 = 0.60
```

每日组合排序使用平滑后的预测值：

```text
原始预测值 → 平滑预测值 → 每日排序 → 选择 Top10%
```

平滑计算只使用当天和过去交易日的预测结果。

## 11. 结果判断标准

### 11.1 主要判断指标

主要判断指标为：

```text
本地留出集综合分
```

实验组 B 或实验组 C 的本地留出集综合分高于实验组 A，说明方法在整体比赛目标上取得改善。

### 11.2 辅助判断指标

同时检查：

- 平均换手率是否下降；
- Top10% 年化超额收益是否保持为正；
- Rank IC 是否保持为正；
- ICIR 是否出现明显下降；
- 验证集与本地留出集之间的性能差距是否扩大。

### 11.3 结果解释

| 结果 | 解释 |
|---|---|
| 综合分提高，换手率下降 | 方法整体有效 |
| 综合分提高，换手率上升 | 收益提升抵消了换手率损失 |
| 综合分下降，换手率下降 | 平滑程度可能过强，排序能力受到影响 |
| 验证集提高，本地留出集下降 | 可能对验证集产生过拟合 |
| 验证集和本地留出集都下降 | 当前方法不适合现有模型 |
