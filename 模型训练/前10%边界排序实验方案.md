# 前 10% 边界排序实验方案

## 1. 实验目标

验证在当前 37 因子、关闭因子依赖训练惩罚的模型上，增加 Top10% 与普通股票之间的边界排序损失，是否能够提高 Top10% 年化超额收益和最终综合分。

本实验先验证新增组件的价值，再调整新增组件的权重。模型结构、预处理、时间划分和正式测试集处理方式保持不变。

## 2. 固定数据划分

| 数据分区 | 时间 | 用途 |
|---|---|---|
| `train_fit` | 2018—2022 | 训练模型参数和 Top10% 训练标签 |
| `validation` | 2023 | 选择训练周期和 alpha，并调用主办方评分程序 |
| `local_holdout` | 2024 | 最终固定配置的历史留出评价 |
| `competition_test` | 2025—2026 | 本实验不处理 |

2023 年的收益标签只用于候选评分，不参与模型参数训练。2024 年只在模型、周期和 alpha 确定后评价一次。

## 3. 固定条件

| 项目 | 固定设置 |
|---|---|
| 输入因子 | 37 个 |
| 模型结构 | 当前 LSTM-Transformer |
| 序列长度 | 20 |
| 随机种子 | 42 |
| 训练批量 | 512 |
| 推理批量 | 4096 |
| 全局排序损失权重 | 0.3 |
| 排序损失 beta | 0.02 |
| 排序损失 tau | 0.02 |
| 因子依赖训练惩罚 | 关闭 |
| 优化器 | AdamW |
| 学习率 | 0.0003 |
| 权重衰减 | 0.0001 |
| 梯度裁剪 | 1.0 |

关闭因子依赖训练惩罚是固定条件。已有结果显示关闭该惩罚的 2024 年综合分高于开启惩罚的实验，避免本实验同时改变两个训练目标。

## 4. 对照组与实验组

### 4.1 对照组 B0

使用当前无依赖惩罚模型：

```text
37 个因子
L_return + 0.3 × L_global-rank
因子依赖训练惩罚关闭
```

对照组优先复用已有无依赖惩罚实验的检查点，并重新整理 2023 年各周期和各 alpha 的官方评分。

### 4.2 实验组 B1

在对照组损失中增加 Top10% 边界排序项：

```text
L_total = L_return + 0.3 × L_global-rank + 0.3 × L_Top-vs-rest
```

实验组 B1 只改变新增边界排序组件，其他设置与对照组完全一致。

## 5. Top10% 标签构造

对训练集每个交易日 (d)，构造官方 Top 组有效集合：

```text
V_d = flag_limit_up == 0 且 y_ret_1d 非缺失
```

按照真实 `y_ret_1d` 降序排序，使用官方规则确定 Top 组数量：

```text
top_count = max(len(V_d) // 10, 1)
```

排序后的前 `top_count` 条记录标记为 Top 组，其余有效记录标记为普通组。

Top 组标签只从训练集真实标签构造。缺少 `y_ret_1d` 的记录不参与 Top 组边界损失。

Top 组标记按 `ts_code + trade_date` 写入训练专用标签表，再按照同一键与训练批次合并。2023 年、2024 年和 2025—2026 年不把真实收益转换成训练标签。

## 6. 新增边界排序损失

设 Top 组为 (T_d)，普通组为 (R_d)，模型预测分数为 (s_i)。边界损失使用 Top 组股票与普通组股票之间的成对排序：

\[
L_{\text{Top-vs-rest}}
=
\frac{1}{|T_d||R_d|}
\sum_{i\in T_d}\sum_{j\in R_d}
\operatorname{softplus}
\left(-\frac{s_i-s_j}{\tau}\right)
\]

该损失要求 Top 组预测分数整体高于普通组。

Top 组内部排序继续由现有 `L_global-rank` 提供。全局排序项也继续约束普通组内部关系，因此本实验不额外增加 Top 组内部和普通组内部的独立权重，保持组件数量可控。

训练批次仍然使用同一交易日采样。边界损失只使用当前批次中同时存在的 Top 组和普通组记录，批次中缺少一类记录时该批次边界损失记为零，并记录 `top_pair_count`。训练完成后必须确认所有训练周期累计存在有效 Top/普通配对。

`L_global-rank` 和 `L_Top-vs-rest` 都按各自有效配对数量取平均，训练记录同时保存两个原始损失、有效配对数量和加权损失贡献，避免两个损失因为配对数量不同产生隐性权重变化。

## 7. 训练周期和 alpha 选择

对 B0 和 B1 的每个有效训练周期生成 2023 年原始预测，比较以下 alpha：

```text
alpha = 1.0、0.7、0.5、0.3
```

平滑公式保持现有定义：

```text
s_t = alpha × p_t + (1 - alpha) × s_(t-1)
```

每只股票独立维护历史状态，第一条预测使用当天原始预测。训练周期和 alpha 都只根据 2023 年结果选择。

## 8. 主办方官方评分

每个候选、训练周期和 alpha 建立独立临时评分目录：

```text
validation_2023/
└── B1_lambda_top_0.3/
    └── epoch_02/
        └── alpha_0.3/
            ├── 测试集_Y.csv
            ├── 测试集_X.csv
            └── 候选预测.csv
```

文件内容使用相同的 2023 年股票日期键：

- `测试集_Y.csv`：`ts_code`、`trade_date`、`y_ret_1d`；
- `测试集_X.csv`：`ts_code`、`trade_date`、`flag_limit_up`；
- `候选预测.csv`：`ts_code`、`trade_date`、`pred`。

调用主办方原版 `赛题五/evaluate.py` 的 `evaluate()` 函数，记录 Rank IC、年化超额收益、平均换手率和综合分。预测文件使用 `候选预测.csv` 名称，不生成 `submission.csv`。

## 9. 选择规则

对照组和实验组统一使用以下选择顺序：

1. 综合分降序；
2. Rank IC 均值降序；
3. Top10% 年化超额收益降序；
4. 训练周期升序；
5. alpha 降序。

候选还必须通过：

- 预测值非有限检查；
- 常数预测检查；
- 每日有效标签数量检查；
- 4096 与 2048 推理批量稳定性检查；
- 本地评分与主办方评分一致性检查。

每个候选还要核对训练身份、输入摘要、程序摘要、随机种子、排序权重和 Top 组标签摘要。任何身份不一致都停止该候选运行。

## 10. 主要判断标准

实验组 B1 具有以下任一结果时，说明新增组件值得继续调参：

- 2023 年综合分高于 B0；
- Top10% 年化超额收益明显提高，且综合分没有下降；
- Rank IC 保持接近 B0，换手率没有明显恶化；
- 多个训练周期和 alpha 都显示相同方向。

如果 B1 只提高 Top10% 年化超额收益，同时 Rank IC 或换手率明显恶化，则记录为目标指标之间的权衡，不直接确定为改进。

组件消融的主要判断使用 B0 和 B1 在 2023 年各自最佳官方综合分比较。不同 alpha 的分数方向、Rank IC 变化、Top10% 超额收益变化和换手率变化作为支持性证据单独记录。

## 11. 后续参数范围

只有 B1 相对 B0 显示出稳定收益后，才比较新增边界损失权重：

```text
lambda_top = 0.15、0.30、0.50
```

全局排序权重暂时保持 0.3，alpha 继续由 2023 年官方评分选择。因子依赖训练惩罚不纳入这一轮权重比较。

## 12. 2024 年历史留出评价

2023 年确定最终候选后，固定：

```text
candidate_id
epoch
lambda_top
alpha
```

仅对固定配置评价 2024 年，记录：

- Rank IC 均值、标准差、ICIR 和正 IC 比例；
- Top10% 年化超额收益；
- 平均换手率；
- 综合分；
- 月度指标。

2024 年结果用于历史留出核验，不回写 2023 年候选选择结果。

新增程序和配置使用独立文件，建议包括：

- `top_boundary_rank_loss.py`：计算 Top/普通边界排序损失；
- `train_top_boundary_rank.py`：执行 B1 训练和周期检查点保存；
- `evaluate_top_boundary_rank.py`：生成预测、平滑预测和官方评分输入；
- `coordinate_top_boundary_rank.py`：调度预检、训练、选择和 2024 年评价；
- `前10%边界排序实验配置.json`：保存候选权重、输入摘要和运行规则。

旧的 `train_cross_section_rank.py`、`evaluate_cross_section_rank.py` 和旧配置不直接改写。

## 14. 资源和交付边界

对照组复用已有检查点，实验组 B1 进行一轮新训练。训练任务使用 RTX 4060 Laptop GPU 单任务顺序运行，保持训练批量 512 和推理批量 4096。

本实验只处理 2018—2024 年的训练、选择和历史留出评价，不处理 2025—2026 年测试集 X，不读取测试集 Y，不生成正式 `submission.csv`。
