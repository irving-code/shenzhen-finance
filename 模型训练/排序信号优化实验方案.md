# 排序信号优化实验方案

## 实验目标

本实验验证排序损失权重和时间平滑参数对比赛综合分的影响，重点观察 Rank IC 与 Top10% 超额收益能否提高，同时保持当前较低换手率。

本实验暂时不改变模型结构、预处理、时间划分和因子依赖诊断方式。

## 固定条件

| 项目 | 固定设置 |
|---|---|
| 输入因子 | 37 个 |
| 训练时间 | 2018—2022 年 |
| 模型选择 | 2023 年 |
| 历史留出 | 2024 年，仅最终评价 |
| 测试集 X | 暂不处理 |
| 测试集 Y | 暂不处理 |
| 模型结构 | 当前 LSTM-Transformer |
| 序列长度 | 20 |
| 随机种子 | 42 |
| 训练批量 | 512 |
| 推理批量 | 4096 |
| 因子依赖训练惩罚 | 关闭 |
| beta | 0.02 |
| tau | 0.02 |
| 优化器 | AdamW |
| 学习率 | 0.0003 |
| 权重衰减 | 0.0001 |

## 候选模型

| 候选 | 37 因子 | 排序损失权重 | 说明 |
|---|---:|---:|---|
| A | 是 | 0.00 | 纯收益回归参考 |
| B | 是 | 0.15 | 弱排序约束 |
| C | 是 | 0.30 | 当前主候选，可复用已有无依赖惩罚实验 |
| D | 是 | 0.50 | 强排序约束 |

候选 C 已有训练结果，可以复用已有检查点并重新整理 2023 年评分。候选 A、B、D 使用独立的新实验目录。

## 训练周期

每个候选保留全部有效训练周期检查点，沿用当前训练周期和早停规则。每个周期都生成 2023 年预测，记录：

- 训练损失；
- Rank IC；
- Top10% 年化超额收益；
- 平均换手率；
- 综合分；
- 预测质量；
- 双批量推理稳定性。

训练周期由 2023 年综合分决定。

## alpha 比较

对每个候选模型的每个有效周期比较以下平滑参数：

```text
alpha = 1.0、0.7、0.5、0.3
```

平滑公式保持现有定义：

```text
s_t = alpha × p_t + (1 - alpha) × s_(t-1)
```

每个股票独立维护历史预测状态。alpha 只使用 2023 年选择。

## 主办方评分方式

为每个候选模型、训练周期和 alpha 建立独立的临时评分目录：

```text
临时评分目录/
├── 测试集_Y.csv
├── 测试集_X.csv
└── 候选预测.csv
```

文件内容使用 2023 年相同股票日期键：

- `测试集_Y.csv`：`ts_code`、`trade_date`、`y_ret_1d`；
- `测试集_X.csv`：`ts_code`、`trade_date`、`flag_limit_up`；
- `候选预测.csv`：`ts_code`、`trade_date`、`pred`。

通过主办方原版 `evaluate.py` 的 `evaluate()` 函数评分。预测文件使用 `候选预测.csv` 名称，不生成 `submission.csv`。

## 选择规则

首先按 2023 年综合分排序。综合分接近时，依次比较：

1. Rank IC 均值；
2. Top10% 年化超额收益；
3. 平均换手率；
4. 训练周期较早者；
5. alpha 较高者。

同时要求候选通过：

- 非有限值检查；
- 常数预测检查；
- 预测质量检查；
- 4096 和 2048 推理批量稳定性检查。

## 重点观察结果

重点查看候选是否出现以下变化：

- Rank IC 高于当前约 0.0607；
- Top10% 年化超额收益保持在约 21.42% 以上；
- 平均换手率仍接近 23.15%；
- 综合分高于当前 2023 年和 2024 年已知结果；
- alpha 降低带来的换手率改善是否牺牲过多 Rank IC 和超额收益。

## 2024 年评价

最终候选由 2023 年确定后，只对这一组固定配置进行一次 2024 年历史留出评价，记录完整指标和月度表现。

2024 年结果用于检验 2023 年选择的稳定性，不参与候选排序和参数调整。
