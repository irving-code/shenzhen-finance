# 严格排序损失消融实验方案

方案日期：2026-10-10。实验编号：`20261010_严格排序损失消融`。

## 一、实验问题

本实验只检验全局同日排序损失对模型预测和比赛综合分的影响。全部候选使用同一份 37 因子输入、同一模型结构、同一数据划分、同一预处理结果、同一训练随机状态规则和同一模型选择规则。因子依赖训练惩罚、Top10% 边界排序损失和其他新增目标在本实验中关闭。

主要比较为：

```text
lambda_rank = 0.00  与  lambda_rank = 0.30
```

`0.00` 组是纯收益回归参考，`0.30` 组是现有全局排序损失设置。`0.15` 和 `0.50` 用于观察排序约束强度变化，不能替代 `0.00` 与 `0.30` 的主要消融比较。

## 二、实验假设

1. 如果排序损失确实改善横截面排序能力，`lambda_rank=0.30` 应在未参与选择的 2024 年留出集上提高 Rank IC 或 Top10% 年化超额收益。
2. 如果排序损失只提高训练期或验证期的排序指标，2024 年综合分不会稳定提高，或者会通过换手率上升抵消收益项改善。
3. 如果排序损失权重过大，`lambda_rank=0.50` 可能损害收益回归精度、预测稳定性或跨年份表现。

## 三、候选组与固定条件

| 候选组 | 全局排序损失权重 | 用途 |
|---|---:|---|
| A | 0.00 | 严格消融基准，纯收益回归 |
| B | 0.15 | 弱排序约束 |
| C | 0.30 | 当前全局排序设置 |
| D | 0.50 | 强排序约束 |

四个候选均使用以下固定条件：

| 项目 | 固定设置 |
|---|---|
| 输入因子 | 37 个，27 个基础因子加 10 个横截面因子 |
| 输入窗口 | 同一股票连续 20 个交易日 |
| 模型 | 一层 LSTM 加一层 Transformer 的回归模型 |
| 投影维度、隐藏维度 | 64、64 |
| Transformer 头数、前馈维度 | 4、128 |
| Dropout | 0.1 |
| 收益损失 | Smooth L1，`beta=0.02` |
| 因子依赖训练惩罚 | 关闭，权重为 0 |
| Top10% 边界排序损失 | 关闭 |
| 优化器 | AdamW |
| 学习率、权重衰减 | `0.0003`、`0.0001` |
| 梯度裁剪 | 1.0 |
| 训练批量、推理批量 | 512、4096；稳定性核验另用 2048 |
| 训练周期 | 最少 6，最多 12 |
| 早停 | 第 6 周期后连续 3 次未改善，最小改善量 `0.0001` |
| 平滑参数 | 固定 `alpha=0.3`，候选选择后可补充记录 `alpha=1.0` 原始预测 |
| 数据划分 | 2018—2022 年训练，2023 年选择，2024 年留出 |
| 随机种子 | 42、43、44 |

每个候选和每个随机种子均从新的随机初始化开始训练。不得从其他排序权重的检查点继续训练，也不得只复用 `lambda_rank=0.30` 的旧检查点后宣称完成严格消融。

## 四、数据和标签协议

训练、验证和留出集必须使用同一份已验收的横截面扩展输入，核对以下身份：

- 数据构建编号：`20261008_横截面排序优化`；
- 输入模式：`extended37`；
- 序列长度：20；
- 训练资格记录：4,510,263 条；
- 2023 年验证预测记录：1,055,569 条；
- 2023 年选择资格记录：1,051,065 条；
- 2024 年留出评估记录：1,091,450 条；
- 2023 年选择日期：241 个；
- 2024 年留出日期：242 个。

标签为下一交易日收益率。训练只使用 2018—2022 年标签，2023 年只用于周期和 alpha 选择，2024 年只在模型选择完成后评价。测试集不参与本实验选择，也不生成正式提交文件。

## 五、训练和评价流程

每个候选执行完整的训练周期。每个周期保存训练损失、收益损失、排序损失、有效股票对数量、预测文件和验证指标。

验证阶段对每个周期执行以下步骤：

1. 生成完整 2023 年验证预测。
2. 按股票顺序计算 `alpha=0.3` 的时间平滑预测。
3. 按选择资格记录计算 Rank IC、Top10% 年化超额收益、平均换手率和综合分。
4. 执行非有限值、常数预测、预测分辨率和双批量排序稳定性检查。
5. 保存原始预测和固定平滑预测的全部指标。

综合分固定为：

```text
final_score = 0.4 × mean_rank_ic
            + 0.3 × annual_top10_excess
            + 0.3 × (1 − mean_turnover)
```

每个候选先按 2023 年固定 `alpha=0.3` 综合分选择周期。综合分差异不超过 `1e-8` 时，依次比较 Rank IC、Top10% 年化超额收益和较早周期。候选周期必须通过数值质量和排序稳定性检查。

所有候选完成选择后，只对每个候选和每个随机种子各自选定的周期执行一次 2024 年留出评价。2024 年指标不能回写训练周期、排序权重或 alpha 的选择。

## 六、严格比较方法

### 6.1 主要比较

主要比较是同一随机种子下 A 组与 C 组的配对比较。每个交易日使用相同股票日期键，计算：

- Rank IC 差值；
- Top10% 日均超额收益差值；
- 平均换手率差值；
- 综合分差值。

先分别计算三个随机种子的 2024 年结果，再计算跨种子的均值、中位数、标准差和 95% 置信区间。置信区间采用按连续五个交易日分块的配对重采样，避免把相邻交易日视为完全独立。

### 6.2 判定标准

排序损失在本实验中得到支持，需要同时满足：

1. C 组相对 A 组的 2024 年跨种子平均综合分差值大于 0；
2. 综合分差值的 95% 配对置信区间不跨 0，或者三个随机种子中至少两个种子的综合分差值为正且没有一个种子下降超过 0.03；
3. C 组的 Rank IC、Top10% 年化超额收益和平均换手率均有完整记录，不能通过缺失指标或质量失败获得比较优势。

如果综合分提高主要来自换手率下降，需要在结论中单独说明收益项是否同步改善。只提高 2023 年验证分而降低 2024 年留出分，判定为未形成稳定收益。

### 6.3 强度比较

B、C、D 的结果用于观察排序权重和指标之间的关系：

- Rank IC 是否随权重增加而持续改善；
- Top10% 年化超额收益是否出现峰值后下降；
- 换手率是否随排序约束增强而上升；
- 训练损失下降是否伴随留出集性能下降。

强度比较只作为支持性证据，主要结论仍以 A 与 C 的严格配对消融为准。

## 七、质量检查和排除规则

任一候选出现以下情况时，该候选周期失去选择资格，并保存具体原因：

- 预测值、标签、损失或梯度出现非有限数值；
- 选择日期出现常数预测；
- 至少 95% 的日期预测分辨率低于规定阈值；
- 4096 与 2048 推理结果的日度排序相关性低于 0.99；
- 两种批量的 Top10% 持仓重叠比例低于 0.95；
- 选择资格记录、日期键或股票日期键出现重复或缺失；
- 评分文件与官方评分程序的记录数量不一致。

候选所有周期均不合格时，记录 `no_eligible_configuration`，不使用该候选参与最终排名。不得用替代模型、填补预测或虚假指标替换失败结果。

## 八、预期交付文件

实验完成后至少交付：

- 固定协议和候选矩阵配置；
- 每个候选、每个随机种子的环境记录和输入摘要；
- 每个周期训练记录、验证指标和检查点；
- 候选周期选择记录及淘汰原因；
- 2023 年逐候选比较表；
- 2024 年逐候选综合指标；
- 按日期配对差值文件；
- 跨种子统计和置信区间文件；
- 双批量稳定性核验；
- 训练依赖关闭核验；
- 实验结果报告。

报告必须明确区分 2023 年选择结果、2024 年留出结果和未参与评价的官方测试集，不把验证集分数写成最终比赛得分。
