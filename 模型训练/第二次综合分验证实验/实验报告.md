# 第二次综合分验证与换手率优化实验报告

## 1. 实验目的

本实验检验两个问题：

1. 使用比赛综合分选择训练周期，是否会选出不同于 Rank IC 选模的模型；
2. 在固定模型上进行预测分数时间平滑，是否能够降低 Top10% 组合换手率并提高本地留出集综合分。

实验组 A、B 使用完全相同的训练检查点。实验组 A 按验证集日度 Rank IC 均值选择周期，实验组 B 按验证集综合分选择周期。实验组 C 使用实验组 B 的模型，在验证集选择时间平滑参数后，应用于本地留出集。

## 3. 评价数据构造与一致性检查

每个预测记录使用以下字段：

```text
ts_code
trade_date
pred
y_ret_1d
flag_limit_up
prediction_eligible
```

涨停字段通过序列索引中的 `source_row_index` 对应标准化数据行读取。预测日期和股票代码按照序列索引的合格记录顺序核对。评价前执行以下检查：

- 预测行数与合格序列数量一致；
- `ts_code + trade_date` 键不存在重复；
- 预测键顺序与序列索引一致；
- 预测值和涨停标记为有限数值；
- 预测值与目标收益按同一股票和同一交易日对齐。

本次所有验证集周期和本地留出集预测均通过这些检查。

统一评价接口已写入 [evaluate_first_lstm_result.py](E:/ChatGPT/ChatGPT_Project/深圳金融比赛赛题五/模型训练/evaluate_first_lstm_result.py)，提供 `evaluate_frame` 和 `evaluate_parquet` 两个入口。

## 4. 比赛指标定义

### 4.1 日度 Rank IC

对每个交易日删除 `y_ret_1d` 缺失记录。当日有效样本少于 30 条时跳过。其余记录计算预测值与下一交易日收益的 Spearman 秩相关系数，再对所有有效交易日取均值。

同时记录：

```text
Rank IC 标准差
ICIR = Rank IC 均值 / Rank IC 标准差
正 IC 交易日比例
```

Rank IC 计算不根据涨停标记删除样本。

### 4.2 Top10% 年化超额收益

每天保留 `flag_limit_up == 0` 且 `y_ret_1d` 非缺失的股票。当日有效股票少于 100 条时跳过。按照预测值降序排列，取：

```text
top_count = max(len(valid) // 10, 1)
```

每日超额收益为 Top10% 组合平均收益减去全部有效股票平均收益，年化结果为每日均值乘以 252。

### 4.3 平均换手率

换手率每天只删除 `flag_limit_up == 1` 的股票，保留 `y_ret_1d` 缺失但具有预测值的记录。当日有效股票少于 100 条时跳过，并将前一持仓集合重置为空。其余相邻有效交易日使用：

```text
turnover = 1 - |current ∩ previous| / |current ∪ previous|
```

持仓数量同样使用 `max(len(valid) // 10, 1)`。

### 4.4 综合分

```text
final_score
    = Rank IC 均值 × 0.4
    + Top10% 年化超额收益 × 0.3
    + (1 - 平均换手率) × 0.3
```

## 5. 实验流程

每个检查点依次执行：

1. 加载固定周期的模型参数；
2. 生成完整验证集预测；
3. 写入验证集预测 Parquet；
4. 补充收益标签、涨停字段和资格字段；
5. 计算 Rank IC、ICIR、Top10% 年化超额收益、换手率和综合分；
6. 写入周期指标表；
7. 分别按照 Rank IC 和综合分选择最佳周期。

随后对实验组 B 的最佳周期测试：

```text
alpha = 1.0、0.9、0.7、0.5、0.3
```

平滑公式为：

```text
s_t = alpha × p_t + (1 - alpha) × s_(t-1)
```

每只股票单独维护历史状态，第一条预测使用当天原始预测值。alpha 只使用验证集综合分选择，本地留出集未参与选择。

### 6.1 周期选择结论

- 实验组 A 选择第 1 周期，验证集 Rank IC 均值为 0.08833603；
- 实验组 B 选择第 1 周期，验证集综合分为 0.17818887；
- 两种选择规则得到相同周期，因此本轮模型选择规则没有带来周期变化；
- 第 1 周期的综合分比第 2 周期高 0.03858181，比第 6 周期高 0.05228122；
- 随训练周期增加，验证集 Rank IC、ICIR 和 `1-换手率` 整体下降，后续周期没有形成收益或交易稳定性补偿。

### 8.2 留出集变化

实验组 A 与 B 选择了同一检查点，因此两者本地留出集指标完全相同。实验组 C 相对于实验组 B：

- 综合分增加 0.10107388，增幅 60.05%；
- 平均换手率降低 0.35483604，降幅 47.08%；
- Rank IC 均值增加 0.00171037；
- Top10% 年化超额收益降低 0.02020360；
- ICIR 从 0.45964074 降至 0.42563194；
- 正 IC 交易日比例从 74.79% 降至 69.83%。

综合分的提升主要来自换手率项的改善。平滑降低了组合调仓频率，同时牺牲了一部分 Top10% 收益和 IC 稳定性。综合分权重下，换手率改善的贡献高于收益指标下降带来的影响。

验证集原始预测综合分为 0.17818887，本地留出集原始预测综合分为 0.16830826，下降 0.00988060。验证集平滑预测综合分为 0.29542950，本地留出集平滑预测综合分为 0.26938214，下降 0.02604736。平滑参数在本地留出集仍保持正向综合分提升，验证集与本地留出集的方向一致。

## 12. 实验结论

1. 本轮六个检查点中，第 1 周期同时取得最高验证集 Rank IC 和最高验证集综合分，实验组 A 与 B 选中同一模型。改变选模指标没有改变最终周期。
2. 时间平滑对当前模型的主要作用是降低换手率。alpha=0.3 在验证集和本地留出集都取得最高综合分，且本地平均换手率从 0.75364327 降至 0.39880723。
3. 平滑后本地 Rank IC 和 Top10% 年化超额收益仍为正，ICIR 和正 IC 交易日比例有所下降。后续比较应继续使用综合分，同时单独跟踪收益稳定性。
4. 官方测试集仍有 2,398 条记录缺少合格序列输入。正式提交前需要补齐这些记录的合法模型输入或修正测试集序列构造规则，再重新执行覆盖检查和 Python、R 双重评价。
