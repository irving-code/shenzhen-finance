# 去除因子依赖惩罚实验计划

方案日期：2026-10-09。方案编号：`20261009_去除因子依赖惩罚`。配套文件：[技术方案](去除因子依赖惩罚技术方案.md)。本文件规定一个新模型训练运行的设计。当前交付范围为两份方案文档；新版配置、程序实施和正式训练属于后续执行工作。

## 1. 实验问题与比较对象

检查移除因子依赖惩罚及其模型选择限制后，模型的 Rank IC、Top10% 年化超额收益、换手率和比赛综合分如何变化。特别关注原始预测与固定平滑预测的年化超额收益是否改善、是否仍为负值，同时完整报告其他指标。

正式运行使用本机 RTX 4060 Laptop GPU、一个 LSTM-Transformer、随机种子 42。比较对象为已经完成的 37 因子实验 `横截面因子与排序损失实验/20261009_local_single`，直接读取其固定模型及评估产物。该模型经过 8 个周期训练，按 2023 年验证集综合分选中第 3 周期。新版采用相同早停规则，实际完成周期数和最终选中周期由新版验证结果决定。

基线 2024 年指标来自[模型结果评估报告](横截面因子与排序损失实验/20261009_local_single/模型结果评估报告.md)：

| 预测处理 | Rank IC | ICIR | Top10% 年化超额收益 | 平均换手率 | 综合分 |
|---|---:|---:|---:|---:|---:|
| 原始预测，`alpha=1.0` | 0.07372240 | 0.41800750 | −0.214422% | 51.921324% | 0.17308172 |
| 固定平滑，`alpha=0.3` | 0.07247200 | 0.40086330 | −2.428154% | 21.264686% | 0.25791028 |

基线选中周期的 2023 年固定平滑指标为 Rank IC `0.08822769805775313`、年化超额收益 `0.21988145705218512`、综合分 `0.336932252318493`，来源为基线 `选定配置.json`。JSON 中收益和换手率采用小数，报告表格采用百分数时明确标注单位。

## 2. 实验改动与固定条件

移除因子依赖约束在训练和模型选择中的作用：

1. 训练总损失仅包含收益损失及权重 0.3 的排序损失。
2. 训练批次使用完整输入执行一次前向计算；因子替换前向计算移至选定模型后的诊断环节。
3. 候选周期资格由数值质量和双批量推理稳定性检查决定。因子依赖比值及参考阈值统计仅作为诊断记录。

其余条件采用已有配置中的数值：

| 项目 | 固定设置 |
|---|---|
| 数据构建 | `20261008_横截面排序优化`，读取同一份已验收存储和索引 |
| 因子与窗口 | 原有 27 个因子＋10 个横截面扩展因子，20 个交易日 |
| 初始化 | 按随机种子 42 从随机初始化开始训练 |
| 模型 | 输入投影 64；一层 LSTM，隐藏维度 64；一层 Transformer，4 个注意力头，前馈维度 128；Dropout 0.1 |
| 优化器 | AdamW，学习率 0.0003，权重衰减 0.0001 |
| 批量与精度 | 同日训练批量上限 512，推理批量 4096，float32 |
| 梯度裁剪 | 范数上限 1.0 |
| 收益损失 | SmoothL1，`beta=0.02` |
| 排序损失 | `tau=0.02`，权重 0.3 |
| 训练采样 | `same_date_v1`，每个周期覆盖全部训练资格记录一次，9,393 个批次 |
| 训练周期 | 最少 6，最多 12；从第 6 周期起计入未改善次数，连续 3 个周期未改善时早停 |
| 早停监控 | 2023 年验证集固定 `alpha=0.3` 的比赛综合分；改善须严格超过 0.0001 |
| 周期选择 | 验证综合分降序；容差 `1e-8`；并列时依次选择 Rank IC 更高、年化超额收益更高、周期更早的模型 |
| 时间平滑 | 固定 `alpha=0.3`；原始预测同时报告 |
| 恢复检查点 | 每 100 个优化步骤保存一次，每个完整周期保存一次 |
| 正式运行数量 | 一个模型、一个随机种子、一个训练进程 |

## 4. 训练目标与模型选择

损失定义为：

```text
L_total = L_return + 0.3 × L_rank
L_return = mean(SmoothL1(p, y, beta=0.02))
L_rank = mean(0.02 × softplus(−sign(y_i−y_j) × (p_i−p_j) / 0.02))
```

排序损失对同日批次中 `i<j`、真实收益不同的股票对等权计算。有效股票对为空时返回保留计算图的零损失。训练记录保存收益损失、排序损失、加权排序损失、总损失、梯度范数、原始预测标准差、样本数量、批次数量和实际耗时。

每个周期生成完整验证预测，按股票日期顺序计算固定平滑，再筛选选择资格记录进行评分。每只股票的首条平滑预测使用首条原始预测：

```text
s_t = 0.3 × p_t + 0.7 × s_(t−1)
综合分 = 0.4 × 平均RankIC + 0.3 × 年化超额收益 + 0.3 × (1 − 平均换手率)
```

候选资格检查采用已有数值质量阈值和双批量稳定性阈值，具体定义见技术方案。因子依赖诊断在唯一模型选定并保存选择记录后执行。参考阈值超限不会改变周期排名、选择记录或后续推理安排。

## 5. 依赖程度诊断

对选定模型的 2023 年验证选择记录和 2024 年合格预测记录，使用已有七组因子来源、训练资格记录目标时间步的逐通道中位数、全部 20 个时间步替换方式计算：

```text
R_g = std(p−q_g, ddof=0) / max(std(p, ddof=0), 1e−8)
```

逐日期聚合完整横截面后计算 float64 总体标准差。记录每组平均比值、逐日比值、超过参考值 0.25 的日期数量、低于或等于参考值的日期比例，并记录旧方案 95% 比例要求的满足情况。上述参考值用于解释与历史方案的区别，诊断输出明确标记 `role=diagnostic_only`。

诊断反映输入替换后的预测敏感度。因子替换会破坏原输入中的部分关联，诊断结果依此限定解释范围；结果不构成因果识别或单个因子收益贡献的证明。

## 6. 结果比较与解释规则

最终报告分开列出原始预测与 `alpha=0.3` 平滑预测，对基线和新版采用同一评价股票日期键、标签及官方评分规则。报告包括：

1. 选定周期的 2023 年验证指标；两个实验各周期的验证指标；第 3 周期对应的相同周期验证比较。
2. 两个选定模型的 2024 年全年、逐日和月度指标，并报告新版减去基线的指标差值。
3. Rank IC、ICIR、Top10% 年化超额收益及绝对收益、换手率、综合分和三项分数贡献。
4. 年化超额收益的正负状态，以及原始预测到平滑预测的变化。收益改善、Rank IC 改善、综合分改善分别描述。
5. 新版选定模型的依赖程度诊断是否满足旧参考要求，以及训练周期和选中周期变化。
6. 环境、输入身份、训练采样摘要、实际耗时、显存和验证覆盖数量。

本实验同时移除训练惩罚与因子依赖选模限制，比较结论适用于这两个改动组成的完整设置。早停和选中周期变化属于该设置运行后的结果。相同周期的验证比较帮助区分训练过程与最终选模结果，2024 年只评估唯一选定模型。单个随机种子、已查看年份的比较无法确定跨年份改善幅度，也无法分别量化两个改动的独立作用。年化超额收益保持负值时，报告保留该数值及负值状态。
