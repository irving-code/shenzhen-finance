# 横截面因子、排序损失与因子依赖约束实验计划

方案日期：2026-10-09。数据构建编号：`20261008_横截面排序优化`。正式训练使用本机 NVIDIA GeForce RTX 4060 Laptop GPU，运行一个模型、一个随机种子。

## 1. 训练目标与固定配置

使用已经验收的 27 个原有因子和 10 个新增横截面因子，训练一个 37 通道、20 个交易日历史窗口的 LSTM-Transformer 模型。损失函数同时包含收益预测、同日股票排序和因子组依赖约束。训练使用随机种子 42，排序损失权重为 0.3，依赖惩罚权重为 0.1。

因子组依赖约束衡量替换一组输入因子后预测的变化，并惩罚超过阈值的变化。该数值描述模型对输入的依赖程度，不用于识别因果效应。实验报告使用“因子组依赖约束”这一名称。

正式训练从新模型参数开始。训练周期通过 2023 年验证集选择，平滑参数固定为已有实验在验证集选出的 `alpha=0.3`。2024 年数据用于选定模型后的本地留出评估。

## 3. 模型训练与因子组依赖约束

| 参数 | 固定数值 |
|---|---|
| 输入、历史窗口 | 37 通道、20 个交易日 |
| 输入投影与 LSTM 隐藏维度 | 各 64 |
| LSTM、Transformer | 各 1 层；Transformer 使用 4 个注意力头、128 维前馈层 |
| Dropout | 0.1 |
| 优化器 | AdamW，学习率 0.0003，权重衰减 0.0001 |
| 同日训练批量上限、推理批量上限 | 512、4096 |
| 收益损失、排序损失 | Smooth L1 `beta=0.02`；排序温度 `tau=0.02`、权重 0.3 |
| 依赖约束 | 比值上限 0.25；超限惩罚权重 0.1；分母下限 `1e-8` |
| 梯度裁剪、计算精度 | 1.0、float32 |
| 训练周期 | 最少 6、最多 12；连续 3 个周期改善不足 0.0001 时早停 |
| 随机种子、设备 | 42、本机 CUDA |

同日采样器在一个周期内使每条 `training_eligible=1` 记录出现一次；固定数据对应 9,393 个批次。损失为：

```text
L = L_return + 0.3 × L_rank + 0.1 × max(R_g − 0.25, 0)²
R_g = std(原始预测 − 替换预测) / max(std(原始预测), 1e−8)
```

七组因子来源分别为：`ret_1d + excess_ret_1d`；`mom_5d + csrank_mom_5d + excess_mom_5d`；`mom_20d + csrank_mom_20d`；`volatility_5d + csrank_volatility_5d`；`amount_shock_5d + csrank_amount_shock_5d`；`intraday_ret + csrank_intraday_ret`；三个 `market_` 因子。每个批次按固定顺序选择其中一组，把该组全部 20 日输入替换为训练资格记录目标时点的逐通道中位数。原始预测与替换预测使用相同的 Dropout 随机状态。正式推理始终使用完整的 37 通道输入。

## 4. 验证、早停与模型选择

每个完整周期生成 1,055,569 条验证预测，按股票时间顺序计算固定 `alpha=0.3` 的平滑预测，再使用 1,051,065 条选择资格记录计算比赛综合分。早停监控值固定为该综合分；第 6 周期之前继续训练，第 12 周期为训练上限。每 100 个优化步骤保存恢复检查点，每个周期保存模型、优化器、随机状态、训练日志、原始预测和验证指标。

候选周期按验证综合分降序排列。分数相差不超过 `1e-8` 时，依次选择 Rank IC 更高、年化超额收益更高、周期更早的模型。候选须通过下列检查：

1. 原始预测、标签、损失、梯度和模型参数均为有限值；每日原始预测的常数输出或严重数值退化使该周期失去选择资格。
2. 使用 4096 与 2048 两种推理批量，至少 99% 的验证选择日期同时满足原始预测 Spearman 相关系数不低于 0.99，以及收益和换手率选股集合重合比例均不低于 95%。
3. 在 241 个验证选择日期上逐日计算七组来源的依赖程度；每组至少 229 个日期满足 `R_g≤0.25`。

依次核验候选周期，保存第一个通过全部检查的模型及其验证选择记录。如果所有已完成周期均不符合条件，保存完整训练和核验报告，并将模型选择状态记为失败；验证阈值保持固定。2024 年留出集不参与周期选择。

## 5. 结果评估与测试集覆盖

选定模型后对 2024 年本地留出集执行一次推理和评估，报告原始预测与固定 `alpha=0.3` 平滑预测的日度 Rank IC、ICIR、Top10% 年化超额收益、平均换手率和综合分。综合分计算为：

```text
综合分 = 0.4 × 平均 Rank IC + 0.3 × Top10% 年化超额收益 + 0.3 × (1 − 平均换手率)
```

评分使用比赛提供的涨停排除、样本数量、Top10% 选择和换手率规则。本地评分程序先以真实数据核对官方评分程序，报告记录每项指标的有效日期与记录数量。2024 年结果属于本地留出集评价。

官方测试集生成 1,597,202 条合格序列预测，并核对股票日期键和有限数值。现有输入还有 2,398 条记录缺少合格的 20 日序列；覆盖审计保留这些键和原因。提交文件要求覆盖官方测试集全部 1,599,600 条记录，覆盖要求未满足时保持“未生成正式提交文件”的状态。

## 6. 本机执行与交付

使用项目 `.venv\Scripts\python.exe` 和本机 RTX 4060 Laptop GPU。运行前核对 CUDA、显存、输入文件摘要、真实 37 通道批次的前向计算、反向计算、参数更新及检查点恢复。训练和评价按单个任务顺序执行，运行记录写入新的独立目录；临时文件写入项目中被 `.gitignore` 忽略的 `tmp/`。

交付文件包含固定配置、环境与输入摘要、预检结果、每周期检查点和指标、七组因子依赖核验、模型选择记录、2024 年本地留出报告、官方测试合格记录预测及覆盖审计。训练中断时只从同一配置与输入身份的检查点恢复。实际耗时由各周期日志记录。
