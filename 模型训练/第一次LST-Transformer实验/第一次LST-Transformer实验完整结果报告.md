# 第一次 LST-Transformer 实验完整结果报告

## 1. 实验范围

本实验面向赛题五的股票下一交易日收益率预测任务。输入为按股票和交易日整理的因子序列，预测目标为下一交易日收益率 `ret_1d`。实验使用统一的未填补因子主表生成模型输入，原始因子文件及因子生成结果未被修改。

数据划分如下：

| 数据部分 | 时间范围 | 用途 |
|---|---|---|
| 训练集 | 2018—2022 年 | 参数拟合与训练 |
| 验证集 | 2023 年 | 早停和模型选择 |
| 本地留出集 | 2024 年 | 训练完成后的独立效果评估 |
| 测试集 | 2025 年及以后 | 生成最终提交预测，不参与训练和模型选择 |

所有时间划分均按日期执行。每支股票独立判断有效数据区间，因此某支股票在较早年份没有有效记录，不影响其他股票使用同一时期的有效数据。

## 2. 评分程序核验状态

本报告中的本地留出集指标没有直接调用比赛目录中的 `evaluate.py`。实际使用的是项目内的 `evaluate_first_lstm_result.py`，在 2024 年本地留出集上按照同样的评分结构计算：

- 日度 Rank IC 均值占 40%；
- Top10% 组合年化超额收益占 30%；
- `1 - 换手率` 占 30%；
- Top10% 组合和换手率计算均剔除涨停股票。

两份程序的评分公式和主要筛选规则一致，但数据接口不同：比赛程序读取 `submission.csv`、`测试集_Y.csv` 和包含 `flag_limit_up` 的 `测试集_X.csv`；本地程序读取 2024 年留出集预测、预处理后的 `limit_up` 和序列索引。因此本报告中的综合分属于本地估计，不能标记为官方测试成绩。只有在具备比赛测试标签并直接运行比赛提供的 `evaluate.py` 后，才能得到官方口径的测试评分。

## 3. 数据处理规则与执行结果

### 3.1 样本资格规则

1. 每支股票先确定有效数据区间。
2. 有效区间开始前的缺失记录不填补，不用于训练。
3. 有效区间结束后的缺失记录不填补，不用于训练。
4. 有效区间内部允许填补，但要求滚动窗口 20 个交易日中至少有 16 个完整交易日。
5. 目标日必须存在有效 `ret_1d`，否则该样本不进入监督训练或本地评估。
6. 测试集保留全部原始行；只有具备完整历史窗口且特征有效的样本用于生成预测，其余样本保留为空预测状态。

### 3.2 预处理流程

| 步骤 | 处理内容 | 防止信息泄漏的规则 | 结果 |
|---|---|---|---|
| 1 | 数据质量检查 | 仅检查，不修改原始因子表 | 完成重复、排序、日期和缺失情况核验 |
| 2 | 时间划分与样本资格判断 | 按日期划分，按股票判断资格 | 建立训练、验证、本地留出和测试范围 |
| 3 | 缺失值处理 | 中位数只由训练集有效样本计算 | 训练集填补 666,008 个单元格；验证集 91,097 个；本地留出集 64,610 个；测试集 1,086,732 个 |
| 4 | 异常值处理 | 连续因子分位点只由训练集有效样本计算 | 使用 0.5% 和 99.5% 分位点截尾；训练集 833,919 个，验证集 122,596 个，本地留出集 351,733 个，测试集 321,337 个 |
| 5 | 标准化 | 均值和标准差只由训练集有效样本计算 | 22 个连续因子进行标准化，离散因子保持原编码 |
| 6 | 序列构造 | 仅使用目标日前的同股票历史窗口 | 序列长度 20 个交易日，未跨股票拼接，未使用目标日之后信息 |
| 7 | 模型输入接口 | 训练、验证、本地留出和测试使用同一字段顺序 | 形成 27 个因子的 `float32` 输入存储，形状为 `(9,499,950, 27)` |

### 3.3 各数据部分的最终样本量

下表为完成资格判断、缺失处理、异常值处理、标准化和序列构造后，实际进入模型接口的样本数量。

| 数据部分 | 原始行数 | 可用于模型输入或评估的样本 | 说明 |
|---|---:|---:|---|
| 训练集 | 5,649,750 | 4,514,536 | 用于模型参数拟合 |
| 验证集 | 1,125,300 | 1,055,569 | 用于早停和模型选择 |
| 本地留出集 | 1,125,300 | 1,091,450 | 用于独立效果评估 |
| 测试集 | 1,599,600 | 1,597,202 | 具备预测条件的样本；测试标签不参与实验 |

训练、验证、本地留出集中的每个样本均绑定股票代码、目标日期、序列起止位置和目标收益率。测试集只生成输入序列和预测结果，不计算监督指标。

## 4. LST-Transformer 模型配置

| 项目 | 设置 |
|---|---|
| 输入因子数 | 27 |
| 历史窗口 | 20 个交易日 |
| 输入类型 | 同股票连续历史序列 |
| 线性投影 | 27 → 64 |
| 循环层 | 单层 LSTM，隐藏维度 64 |
| 注意力层 | 单层 Transformer Encoder，4 个注意力头，前馈层维度 128 |
| 输出层 | 取最后一个时间步，经多层感知器输出一个收益率预测值 |
| 损失函数 | Smooth L1 Loss，`beta=0.02` |
| 优化器 | AdamW |
| 学习率 | `3e-4` |
| 权重衰减 | `1e-4` |
| 批大小 | 512 |
| 梯度裁剪 | 最大范数 1.0 |
| 最大训练轮数 | 30 |
| 早停耐心轮数 | 5 |
| 随机种子 | 42 |
| 运行设备 | NVIDIA GeForce RTX 4060 Laptop GPU，CUDA |

训练只读取训练集样本，验证集用于选择最佳轮次，本地留出集只在训练结束后评估，测试集不参与任何参数选择。

## 5. GPU 训练结果

训练使用 CUDA 设备完成，共运行 6 个轮次，因验证集日度 Rank IC 连续下降而触发早停。最佳模型为第 1 轮保存的模型。

| 轮次 | 训练损失 | 验证损失 | 验证集日度 Rank IC |
|---:|---:|---:|---:|
| 1 | 0.01344851 | 0.00916388 | 0.08833708 |
| 2 | 0.01226996 | 0.00916432 | 0.07486660 |
| 3 | 0.01187897 | 0.00923943 | 0.07226338 |
| 4 | 0.01161988 | 0.00918799 | 0.06987788 |
| 5 | 0.01145102 | 0.00924836 | 0.06914788 |
| 6 | 0.01131034 | 0.00931979 | 0.06718104 |

最佳验证集日度 Rank IC 为 `0.08833708`，对应第 1 轮模型。训练损失继续下降但验证集 Rank IC 下降，说明后续轮次出现了泛化效果减弱，因此最终采用最佳轮次模型，而不是最后一轮模型。

## 6. 本地留出集效果

本地留出集为 2024 年数据，共 242 个交易日、1,091,450 个有效评估样本。下表中的综合分按照项目当前采用的比赛指标权重计算，仅作为本地估计，不代表官方测试成绩。

| 指标 | LST-Transformer | 当前日 `ret_1d` 基线 |
|---|---:|---:|
| 日度 Rank IC 均值 | 0.08169467 | 0.01340970 |
| 日度 Rank IC 标准差 | 0.17774012 | — |
| ICIR | 0.45962987 | 0.06559764 |
| Rank IC 为正的交易日比例 | 74.79% | 53.72% |
| Top10% 年化超额收益 | 20.61% | -45.49% |
| Top10% 年化收益 | 19.65% | -46.45% |
| 平均换手率 | 75.36% | 92.02% |
| `1 - 换手率` | 0.24635907 | 0.07983055 |
| 按比赛权重计算的本地综合分 | 0.16841623 | -0.10715711 |

模型相对当前日收益率基线的本地综合分差值为 `0.27557334`。本地结果显示模型在横截面排序、方向稳定性和 Top10% 组合收益方面具备正向信号；平均换手率较高，交易成本敏感性仍然需要在后续实验中单独分析。

## 7. 结果判断

1. 数据处理链条已经形成从资格判断、缺失处理、异常值处理、标准化、序列构造到模型输入的完整流程。
2. 训练集统计量没有使用验证集、本地留出集和测试集数据，时间边界与股票边界均已保留。
3. 第 1 轮模型是本次实验的最佳模型，后续轮次验证集 Rank IC 下降，最佳模型文件应继续用于测试集预测。
4. 本地留出集日度 Rank IC 均值为 0.08169467，ICIR 为 0.45962987，正 Rank IC 交易日比例为 74.79%。这些指标支持模型具有一定的横截面预测能力。
5. 测试集没有真实收益率标签，因此当前无法给出官方测试集 Rank IC、收益率或比赛最终得分。测试集只能用于生成提交文件。
6. 本地留出集指标使用 2024 年作为独立评估范围，不能替代官方测试结果；后续需要保留测试集的预测文件并按比赛提交格式生成最终结果。
