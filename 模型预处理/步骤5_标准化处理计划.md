# 第五步：标准化处理计划

## 1. 处理目标

在第四步异常值处理结果的基础上，使用 `train_fit` 合格样本估计输入因子的缩放参数，并将同一组参数应用到验证集、本地留出集和官方测试集，为后续 20 日序列构造提供统一输入尺度。

本步骤只处理模型输入因子，不处理 `y_ret_1d`。原始因子主表、第三步填充结果和第四步异常值处理结果均保持不变。

## 2. 数据范围

| 区间 | 日期范围 | 用途 |
|---|---|---|
| `train_fit` | 2018-01-02 至 2022-12-31 | 估计标准化参数和训练模型 |
| `validation` | 2023-01-01 至 2023-12-31 | 选择超参数和训练轮数 |
| `local_holdout` | 2024-01-01 至 2024-12-31 | 本地留出评价 |
| `competition_test` | 2025-01-02 至 2026-06-08 | 生成最终预测 |

输入文件为第四步的四个 Parquet 文件：

```text
模型预处理/步骤4_异常值处理/train_fit_异常值处理.parquet
模型预处理/步骤4_异常值处理/validation_异常值处理.parquet
模型预处理/步骤4_异常值处理/local_holdout_异常值处理.parquet
模型预处理/步骤4_异常值处理/competition_test_异常值处理.parquet
```

## 3. 参数来源与时间隔离

所有连续因子的标准化参数只使用：

```text
区间 = train_fit
sample_eligible = 1
日期 = 2018-01-02 至 2022-12-31
```

验证集、本地留出集和官方测试集的因子数值不参与均值、标准差或其他缩放参数的计算。`y_ret_1d` 只作为训练目标保留，不参与输入标准化。

对每个连续因子 `x_k` 计算：

```text
mean(k)  = train_fit 合格样本均值
std(k)   = train_fit 合格样本总体标准差，ddof=0
count(k) = 有效值数量
min(k)   = 来源样本最小值
max(k)   = 来源样本最大值
```

如果某个连续因子的标准差为 0，立即停止处理并报告该因子，不自动使用替代标准差。

## 4. 因子处理规则

### 4.1 连续因子

以下 22 个因子使用 Z-score 标准化：

```text
ret_1d
mom_3d
mom_5d
mom_10d
mom_20d
mom_20d_skip1
volatility_5d
volatility_20d
range_1d
gap_1d
true_range_1d
intraday_ret
close_position
body_ratio
upper_shadow
lower_shadow
log_amount
log_volume
delta_log_amount
delta_log_volume
amount_shock_5d
amount_shock_20d
```

转换公式：

```text
x_standardized(k) = (x(k) - mean(k)) / std(k)
```

### 4.2 离散和状态因子

以下字段保持原始数值含义：

```text
body_direction
limit_up
limit_down
missing_price_volume
```

取值约束为：`body_direction` 属于 `-1、0、1`，其余三个字段属于 `0、1`。

`history_available_count_20d` 保留原始计数，并新增：

```text
history_available_ratio_20d = history_available_count_20d / 20
```

比例字段位于 `0` 至 `1`，不需要从验证集或测试集估计参数。

## 5. 四个区间的转换

### 5.1 训练、验证和本地留出

有效行情区间内部的记录使用 `train_fit` 参数标准化。股票有效区间外的记录保留空值，不进入训练序列。`sample_eligible=1` 的目标日及其 20 日窗口中的连续因子必须为有限数值。

### 5.2 官方测试集

官方测试集全部记录均保留。连续因子使用 `train_fit` 的均值和标准差转换，状态字段继续保留：

```text
inside_valid_interval
pre_valid_interval
post_valid_interval
current_market_valid
sample_eligible
```

测试集不参与任何参数重新估计。

## 6. 缺失值和边界规则

1. 第三步保留的训练区间外空值继续保留；
2. 第三步已经填充的有效区间内部因子进入标准化；
3. 标准化过程不执行再次填充、前向填充或后向填充；
4. `missing_price_volume` 不因标准化而改变；
5. `history_available_count_20d` 的原始计数不覆盖；
6. 官方测试区间外记录继续保留状态字段并生成模型输入。

## 7. 输出文件

新建目录：

```text
模型预处理/步骤5_标准化处理/
```

输出：

```text
参数_train_fit.json
标准化统计.csv
训练集_train_fit_标准化.parquet
验证集_标准化.parquet
本地留出集_标准化.parquet
测试集_标准化.parquet
步骤5_标准化处理报告.md
步骤5_标准化处理结果.json
```

每个输出文件保留键字段、标准化后的实验因子、状态字段、第三步和第四步的审计字段。训练文件保留 `y_ret_1d`，验证、留出和测试文件不新增标签。

## 8. 结果检查

### 8.1 参数来源

检查参数来源日期、来源区间、来源行数和来源股票数，确认验证集、本地留出集和测试集没有参与计算。

### 8.2 数值范围

对 `train_fit` 合格样本检查每个连续因子的标准化均值接近 0、标准差接近 1，并确认没有正无穷或负无穷。对四个区间检查状态因子取值合法，`history_available_ratio_20d` 位于 0 至 1。

### 8.3 数据完整性

检查四个输出文件的行数、股票数、日期范围、行顺序和 `ts_code + trade_date` 唯一性。检查 `y_ret_1d` 与第四步输入保持一致，区间外训练记录没有进入训练序列，前面各步骤的文件没有修改。

## 9. 后续序列构造接口

标准化完成后，序列构造阶段使用四个标准化 Parquet 文件，按同一 `ts_code` 取连续 20 个交易日：

```text
t-19, t-18, ..., t
```

训练、验证和本地留出只使用 `sample_eligible=1` 的目标日，官方测试集按全部提交记录生成预测输入。

## 10. 验收标准

1. 连续因子的参数全部来自 `train_fit` 合格样本；
2. 验证集、本地留出集和测试集没有参与参数计算；
3. 训练合格样本标准化均值接近 0、标准差接近 1；
4. 离散和状态因子保持原始取值含义；
5. 四个输出文件行数、键字段和标签正确；
6. 区间外训练记录不进入训练序列；
7. 原始因子主表及前面步骤输出文件保持不变。
