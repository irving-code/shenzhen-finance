# 第三步：缺失值处理计划

## 1. 处理目标

为第一次 LST-Transformer 实验生成可用于模型输入的缺失值处理数据，同时保留统一因子主表的原始空值。

本步骤解决以下问题：

1. 明确每只股票哪些记录属于有效行情区间；
2. 识别可以用于训练、验证和本地留出评价的目标日；
3. 只用 `train_fit` 合格样本估计填充参数；
4. 将填充参数应用于验证集、本地留出集和官方测试集；
5. 检查填充是否把股票有效区间外的记录误当作训练数据；
6. 输出后续序列构造需要的状态字段和审计结果。

本步骤不覆盖 `因子数据` 目录中的统一未填补因子主表，也不执行标准化、异常值截断和固定长度序列构造。

## 2. 输入数据

使用以下 Parquet 文件：

```text
因子数据/训练集_第一次LST-Transformer因子.parquet
因子数据/测试集_X_第一次LST-Transformer因子.parquet
```

第一次实验的 27 个因子为：


训练数据按照以下时间区间使用：

| 区间 | 日期范围 | 用途 |
|---|---|---|
| `train_fit` | 2018-01-02 至 2022-12-31 | 估计填充参数和标准化参数 |
| `validation` | 2023-01-01 至 2023-12-31 | 选择训练轮数和超参数 |
| `local_holdout` | 2024-01-01 至 2024-12-31 | 本地留出评价 |
| `competition_test` | 2025-01-02 至 2026-06-08 | 生成最终预测 |

## 3. 按股票确定有效行情区间

### 3.1 完整行情日定义

对股票 `i` 在交易日 `t` 定义：

```text
market_complete(i,t) = 1，当 missing_price_volume(i,t) = 0
market_complete(i,t) = 0，否则
```

完整行情日要求六个量价字段均有数值：

```text
open, high, low, close, vol, amount
```

### 3.2 股票级边界

对每个 `ts_code=i` 分别计算：

```text
first_valid_date(i) = 股票 i 的最早完整行情日
last_valid_date(i)  = 股票 i 的最晚完整行情日
```

有效行情区间定义为：

```text
[first_valid_date(i), last_valid_date(i)]
```

所有区间判断都按 `ts_code` 单独进行，不设置全市场统一的起始日期。一只股票在 2019 年前没有有效记录，只排除该股票 2019 年前的记录；其他股票仍可使用 2018 年记录。

### 3.3 区间状态字段

对每条记录生成：

```text
inside_valid_interval
pre_valid_interval
post_valid_interval
current_market_valid
```

这些字段只描述数据状态，不作为预测因子输入。

### 3.4 区间范围隔离

有效行情边界按数据用途分别计算：

| 数据区间 | 边界计算范围 | 允许参与填充参数估计 |
|---|---|---|
| `train_fit` | 2018-01-02 至 2022-12-31 | 是 |
| `validation` | 2018-01-02 至 2023-12-31 的历史信息，资格判断只作用于 2023 年目标日 | 否 |
| `local_holdout` | 2018-01-02 至 2024-12-31 的历史信息，资格判断只作用于 2024 年目标日 | 否 |
| `competition_test` | 训练集和测试集的 X 字段，用于测试记录状态判断 | 否 |

每个目标日只使用该日期及更早的 X 信息完成因子和状态判断。`validation`、`local_holdout` 和 `competition_test` 的任何因子数值都不能进入 `train_fit` 填充参数计算。

## 4. 目标日与序列资格

### 4.1 目标日定义

对目标日 `t`，模型输入窗口使用同一股票的最近 20 个交易日：

```text
t-19, t-18, ..., t
```

标签为目标日记录中的：

```text
y_ret_1d(t) = close(t+1) / close(t) - 1
```

### 4.2 训练样本资格

训练、验证和本地留出样本必须同时满足：

1. 目标日位于该股票的有效行情区间内；
2. 目标日的 `y_ret_1d` 有效；
3. 目标日前最近 20 个交易日中至少 16 天的六个量价字段完整；
4. 输入窗口的 20 条记录均属于该股票的有效行情区间。

第 4 条用于确保首个有效行情日前和最后有效行情日后的记录不会进入训练序列。有效区间内部出现的缺失属于允许处理的内部缺失。

定义最终资格标记：

```text
sample_eligible = target_inside_valid
                  and label_valid
                  and history_available_count_20d >= 16
                  and window_inside_valid
```

其中：

```text
window_inside_valid = 20 个输入日均处于该股票有效行情区间内
```

官方测试集没有标签，保留全部记录用于生成预测；测试集记录同时保留上述区间状态和历史有效性字段。

## 5. 填充参数估计

### 5.1 参数来源

每个因子的填充值只使用 `train_fit` 区间中满足 `sample_eligible` 的记录估计。

`train_fit` 的参数来源严格限定为 2018-01-02 至 2022-12-31，参数文件必须记录来源日期范围、来源行数和来源股票数。

参数估计过程不得读取：

- `validation` 的因子数值；
- `local_holdout` 的因子数值；
- `competition_test` 的因子数值；
- 训练标签的数值内容。

`y_ret_1d` 只用于判断标签是否为空，不参与中位数计算。

### 5.2 填充值统计量

对每个因子 `k` 计算：

```text
fill_value(k) = train_fit 合格样本中因子 k 的中位数
```

同时记录：

```text
train_valid_count(k)
train_missing_count(k)
train_missing_rate(k)
fill_value(k)
```

中位数可以降低极端行情对填充值的影响。参数文件中保存完整数值和样本数量，保证后续实验能够复现。

如果某个因子在合格 `train_fit` 样本中没有任何有效值，则停止处理并报告该因子，避免自动使用未经验证的零值或其他替代值。

### 5.3 状态因子处理

`missing_price_volume` 和 `history_available_count_20d` 是数据状态因子。先检查它们是否存在空值：

- `missing_price_volume` 应为 0 或 1；
- `history_available_count_20d` 应位于 0 至 20。

若状态因子出现空值，单独记录并停止进入模型输入填充，不能把状态缺失静默转换为普通数值。

## 6. 填充规则

### 6.1 训练、验证和本地留出

对 `train_fit`、`validation` 和 `local_holdout`：

```text
因子有数值 -> 保留原值
因子为空且记录在有效行情区间内 -> 使用 train_fit 的 fill_value(k)
因子为空且记录在有效行情区间外 -> 保留为空
```

区间外记录不生成训练样本，也不进入后续 LST-Transformer 序列。

### 6.2 官方测试集

官方测试集需要为全部原始记录生成预测。测试集使用 `train_fit` 填充值处理模型输入，并保留：

```text
inside_valid_interval
pre_valid_interval
post_valid_interval
history_available_count_20d
missing_price_volume
```

测试集区间外记录的状态字段用于标记预测可信程度，不参与任何填充参数估计，也不参与训练。

### 6.3 填充公式

对可填充范围内的普通因子 `x_k`：

```text
x_filled(k) = x_k                 , x_k 有效
x_filled(k) = fill_value(k)       , x_k 缺失且允许填充
x_filled(k) = NaN                 , x_k 缺失且记录在训练禁止区间
```

不使用前向填充、后向填充、零值替换和验证集或测试集统计量。

## 8. 结果检查

### 8.1 数据完整性

检查：

1. 填充前后行数一致；
2. `ts_code + trade_date` 唯一；
3. 股票数量和日期范围不变；
4. 行顺序保持一致；
5. 训练、验证、本地留出和测试记录没有交叉写入。

### 8.2 缺失处理检查

按区间和因子统计：

```text
填充前缺失数量
填充后缺失数量
实际填充数量
区间外保留缺失数量
```

合格训练样本的模型输入因子不应再有普通数值因子空值。训练禁止区间的空值必须保留，并且这些记录的 `sample_eligible` 应为 0。

### 8.3 信息边界检查

检查：

1. `参数_train_fit.json` 的参数来源只包含 `train_fit` 合格样本；
2. 验证集、本地留出集和测试集没有参与参数计算；
3. 所有填充值与对应训练参数文件一致；
4. 状态字段没有被普通因子填充值覆盖；
5. 每只股票的区间外记录没有进入训练资格样本；
6. 某一只股票缺失不会改变其他股票的区间判断和样本资格。

### 8.4 后续序列构造接口

本步骤完成后，序列构造阶段只读取：

```text
sample_eligible = 1
```

的训练、验证和本地留出目标日，并按照同一 `ts_code` 取连续 20 个交易日。官方测试集按提交所需记录生成预测输入，同时保留区间状态字段。

## 9. 验收标准

第三步通过的条件为：

1. 填充参数全部来自 `train_fit` 合格样本；
2. 每只股票独立确定有效区间；
3. 2019 年才开始有效的股票不会占用其 2018 年缺失记录，其他股票仍可使用 2018 年样本；
4. 训练禁止区间没有被填充，也没有进入训练资格样本；
5. 内部缺失已按统一训练参数处理；
6. 合格训练样本的普通因子没有空值；
7. 官方测试集保留全部原始记录并能够生成模型输入；
8. 报告、参数文件和填充后数据能够互相核对。
