## 1. 输入、边界与产物

预处理读取原有因子、四个标准化分区、四个序列索引、旧特征存储和股票元数据，生成十个新通道及四组实验共用的样本索引。原有 27 通道从旧存储只读取得，不重新计算。数据处理接口返回 NumPy 数组；模型训练、损失计算和收益评价使用独立任务。

| 输入 | 必须读取的内容 | 作用 |
|---|---|---|
| `因子数据/训练集_第一次LST-Transformer因子.parquet` | 股票、日期、行情缺失标记和六个源因子 | 2018—2024 年的同日特征 |
| `因子数据/测试集_X_第一次LST-Transformer因子.parquet` | 相同字段 | 官方测试日期的同日特征 |
| `模型预处理/步骤5_标准化处理/` 四个标准化文件 | 股票、日期、`sample_eligible`、`inside_valid_interval`、`limit_up` | 继承参数估计资格、允许处理范围和评价状态 |
| `模型预处理/步骤6_序列构造/序列索引_{split}.parquet` | 来源行号、面板身份、股票内行号、窗口起点、预测资格、收益标签 | 共同样本索引及窗口位置 |
| `模型预处理/步骤7_模型输入接口/模型输入接口元数据.json` | 27 列顺序、存储形状、分区数量 | 校验旧输入结构 |
| `模型预处理/步骤7_模型输入接口/股票元数据.parquet` | `stock_id`、`feature_offset`、`stock_length` | 十通道存储地址 |
| `模型预处理/步骤7_模型输入接口/特征存储.dat` | 原有 27 个 `float32` 通道 | A、C 直接读取；B、D 拼接读取 |
| 赛题说明与真实交易日期 | 收益定义、下一交易日 | 核验标签实现日期 |

四个分区名称固定为 `train_fit`、`validation`、`local_holdout` 和 `competition_test`。来源元数据记录旧存储的 9,499,950 行、27 列及 4,650 支股票。新存储预期为相同行数、十列、`float32`；构建时重新核验来源元数据和实际文件。

每个输入文件登记规范化绝对路径、字节数、行数、字段类型、日期范围与 SHA-256 摘要。读取批次上限为 200,000 行。文件缺失、必需字段缺失、重复股票日期键或元数据与实际文件冲突时立即终止构建。

## 3. 共同索引与时间字段

### 3.1 保留原有身份

新建 `样本索引_{split}.parquet`，每个原有序列索引记录对应一条新记录。使用 `(source_split, source_row_index)` 定位原有分区行，使用 `(ts_code, target_date)` 连接因子表和标准化文件，使用 `panel_row_id` 审计面板身份。所有连接要求双向一对一、无遗漏，排序后按 `target_date, ts_code` 保存。

| 字段 | 类型 | 规则 |
|---|---|---|
| `source_split`、`source_row_index` | 字符串、int64 | 原有分区和该分区标准化文件行号 |
| `panel_row_id`、`ts_code`、`target_date` | int64、字符串、int64 | 原有面板身份、股票代码、目标交易日期 |
| `stock_id`、`feature_offset`、`target_stock_row_number` | int32、int64、int64 | 按旧股票元数据确定 |
| `window_start_stock_row_number` | 可空 int64 | 直接继承旧序列索引；20 日窗口起点 |
| `sample_eligible` | int8 | 继承原有样本资格，并核对标准化文件 |
| `inside_valid_interval` | int8 | 继承标准化文件，核对旧索引的 `target_inside_valid_interval` |
| `preprocess_fit_eligible` | int8 | `source_split=train_fit` 且 `sample_eligible=1` |
| `prediction_eligible` | int8 | 直接继承原有序列资格 |
| `training_eligible`、`selection_eligible` | int8 | 按本节标签日期规则新增 |
| `label_realization_date`、`y_ret_1d` | 可空 int64、float32 | 带标签分区保留；官方测试分区省略 |
| `flag_limit_up` | float32 | 由标准化文件的 `limit_up` 映射 |

`sample_eligible` 与 `prediction_eligible` 分别表示原有预处理样本资格和原有序列资格。`preprocess_fit_eligible` 决定新增特征参数估计样本；`training_eligible` 决定模型训练目标行。三个用途分别记录、分别核验。

### 3.2 标签实现日期

从真实交易日期建立 `target_date` 到下一交易日的映射。实施时依据赛题说明和相邻日期的真实价格核验 `y_ret_1d` 的收益口径、单位和实现日期。日期序列跨年连续；股票行情缺失不改变市场下一交易日映射。

- `training_eligible=1` 要求 `source_split=train_fit`、原有 `prediction_eligible=1`、收益标签有限、实现日期已知，且实现日期不晚于 2022 年最后交易日。
- `selection_eligible=1` 要求 `source_split=validation`、原有 `prediction_eligible=1`，且实现日期位于 2023 年验证交易日期范围。
- 其余分区的两个标记设为零。本地留出集和官方测试集继续使用原有预测资格。

输出 `交易日期表.parquet` 和 `标签边界排除清单.parquet`。清单保留股票、目标日期、实现日期、原资格、新资格和排除原因。报告分别统计原有合格数量、边界排除数量和最终数量。未知实现日期不得进入训练或验证选择。

### 3.3 适用范围

原有 `sample_eligible` 要求目标记录处于原有有效区间、标签存在，并满足历史行情条件；原有有效区间使用截至对应分区结束时可以观察到的股票行情边界确定。这些原有条件延续到新增特征的参数估计样本和四组共同样本。因而实验结论对应既定合格记录集合；该集合的定义不得表述成逐日实时可计算的选股资格。十个原始因子的当日横截面集合独立计算，不使用这些资格标记。

## 4. 十个原始因子

### 4.1 字段与完整交易日

生成函数只接收以下字段：

```text
ts_code, trade_date, missing_price_volume,
ret_1d, mom_5d, mom_20d, volatility_5d, amount_shock_5d, intraday_ret
```

从原始因子 Parquet 按来源与年份整理记录，每次计算一个完整交易日的全部股票。原始来源行号 `raw_source_row_index` 与标准化分区行号 `source_row_index` 分开保存，通过股票和日期核对。因子计算的输入不含 `y_ret_1d`、有效区间标记、训练资格或未来日期统计。源数值保留 `float32` 来源精度，统计运算转换为 `float64`。

对源因子 `f` 和日期 `t`，有效集合定义为当天 `missing_price_volume=0` 且 `f` 为有限数值的股票。每个源因子独立确定集合。当日有效的涨停股票和标签缺失股票均参与对应统计。

### 4.2 固定输出列

| 通道 | 字段 | 原始值计算 |
|---:|---|---|
| 28 | `csrank_mom_5d` | 当日 `mom_5d` 升序平均名次比例 |
| 29 | `csrank_mom_20d` | 当日 `mom_20d` 升序平均名次比例 |
| 30 | `csrank_volatility_5d` | 当日 `volatility_5d` 升序平均名次比例 |
| 31 | `csrank_amount_shock_5d` | 当日 `amount_shock_5d` 升序平均名次比例 |
| 32 | `csrank_intraday_ret` | 当日 `intraday_ret` 升序平均名次比例 |
| 33 | `excess_ret_1d` | 个股 `ret_1d` 减当日有效集合的 `ret_1d` 中位数 |
| 34 | `excess_mom_5d` | 个股 `mom_5d` 减当日有效集合的 `mom_5d` 中位数 |
| 35 | `market_mean_ret_1d` | 当日有效 `ret_1d` 的均值 |
| 36 | `market_breadth_1d` | 当日有效 `ret_1d` 严格大于零的比例 |
| 37 | `market_dispersion_1d` | 当日有效 `ret_1d` 的总体标准差，`ddof=0` |

有效集合数量 `N≥2` 时，排名比例为 `(平均名次−1)/(N−1)`；并列值取平均名次。`N=1` 时该股票排名比例为 0.5；`N=0` 时该字段保留缺失。未进入相应集合的个股，其排名和相对收益保留缺失。三个市场字段按日期广播至当日全部来源记录；有效收益集合为空时保留缺失，只有一支股票时离散度为零。上涨比例分母包含零收益股票。

`volatility_5d` 沿用原有五日收益样本标准差定义，源因子计算使用 `ddof=1`；`amount_shock_5d` 沿用现有因子表字段。输出 `训练来源_横截面因子.parquet`、`测试来源_横截面因子.parquet`、`每日集合统计.parquet` 和 `生成审计.json`，记录来源身份、日期集合规模、原始与有效数量、非有限值数量及相关统计。

## 5. 处理参数与变换

### 5.1 参数估计样本

参数估计样本固定为旧 `train_fit` 中 `sample_eligible=1` 的记录，预计 4,514,536 条。`preprocess_fit_eligible` 的股票与日期键须与原有步骤 3—5 使用的参数估计记录完全相同；同时核验数量、逐条身份和排序后键摘要。每条目标记录计入一次，重叠的 20 日窗口不增加该记录权重。市场字段在同日多支股票上的重复值按股票记录等权计入。

参数估计只使用该集合的新增特征值。验证、留出、测试记录不参与参数估计；标签实现日期排除记录仍依照原有 `sample_eligible` 定义参加参数估计。每列记录有限原始值数量、缺失数量、估计日期范围和参数来源摘要。

### 5.2 六个有界特征

对五个 `csrank_` 字段和 `market_breadth_1d`，先检查全部有限原始值位于 `[0,1]`，再从参数估计样本的有限原始值计算中位数。允许处理的记录用该中位数填补缺失，并计算 `2 × value − 1`。参数文件记录中位数、有效值数量和转换公式。这六列使用专用转换，不估计分位截断边界和均值标准差。

### 5.3 四个连续特征

`excess_ret_1d`、`excess_mom_5d`、`market_mean_ret_1d`、`market_dispersion_1d` 分别执行以下顺序：

1. 从参数估计样本的有限原始值计算中位数 `m`，使用 `m` 填补该样本缺失值，得到 `v_fill`。
2. 在全部 `v_fill` 上用线性插值计算 0.005、0.995 分位数，分别记为 `lo`、`hi`。
3. 将 `v_fill` 截断至 `[lo, hi]`，得到 `v_clip`。
4. 在全部 `v_clip` 上计算均值 `μ` 和总体标准差 `σ`，`ddof=0`。
5. 对允许处理的每条面板记录，按固定 `m` 填补、按固定 `[lo, hi]` 截断，并计算 `(v_clip−μ)/σ`。

每列独立计算精确分位数。训练来源整列缺失、参数非有限、`lo>hi`、`σ=0` 或输出非有限时终止构建。参数文件分别保存 `m`、`lo`、`hi`、`μ`、`σ`、线性插值方法、`ddof`、计算精度和来源摘要。

### 5.4 允许处理范围

十列统一使用 `inside_valid_interval=1` 或 `source_split=competition_test` 作为填补和尺度转换条件。训练、验证、本地留出直接继承原标准化文件的有效区间标记；官方测试处理全部记录。范围外保留新增原始值及缺失位置。全部面板地址仍须写入；有限性要求作用于全部合格模型窗口。

`float64` 计算结果写入 `float32` 存储。核验有限值转换后依然有限，记录最大绝对误差和相对误差；原始缺失位置在未处理范围内保持缺失。按分区和特征记录允许处理、保留原值、填补、上下截断及非有限值的数量。

## 6. 十通道存储与窗口读取

### 6.1 地址与写入

从旧股票元数据读取 `feature_offset` 和 `stock_length`，使用旧序列索引的 `target_stock_row_number` 计算 `store_row_index=feature_offset+target_stock_row_number`。`panel_row_id` 用于身份核验，实际存储地址使用 `store_row_index`。四个分区的每条面板记录与新增原始因子按股票和日期一对一连接，写入十个固定顺序的 `float32` 数值。

新 `新增特征存储.dat` 的预期形状为 `(9499950,10)`，实际形状由核验后的旧元数据决定。构建时维护每个地址的写入标记，逐批检查越界、重复和遗漏；完成后每个地址恰好写入一次。文件刷新、关闭并以只读方式重新打开后进行结果核验。旧 27 通道存储全程只读。

### 6.2 读取接口

```text
CrossSectionInputReader(base_metadata_path, extra_metadata_path,
                        index_path, feature_mode)
read_batch(index_positions)
iter_inference_batches(batch_size=4096)
SameDateBatchSampler(index, seed, epoch, max_batch_size=512)
```

对窗口起点 `k` 和该股票偏移 `o`，一次读取 `o+k` 至 `o+k+19` 的连续地址。窗口包含单一股票、20 条严格递增的交易日期，末端等于 `target_date`。`base27` 返回 `(B,20,27)`；`extended37` 按列顺序拼接旧 27 通道与新十通道，返回 `(B,20,37)`。两个模式使用同一共同索引和同一窗口地址。返回批次包含 `x`、`ts_code`、`target_date`、`panel_row_id`、`prediction_eligible`；带标签分区另含 `y`，测试批次省略标签。

`训练位置_train_fit.parquet` 保存排序后的索引行位置；`日期索引_train_fit.parquet` 保存每个目标日期对应的训练位置起止区间及数量。采样器根据种子、周期和固定用途编号生成独立随机状态，排列日期和当日股票，将每个日期的股票均衡分成最多 512 条的批次。每个最终训练目标在一个周期内出现一次；四组实验使用相同批次身份和顺序。

## 8. 验收条件

| 检查 | 必须达到的结果 |
|---|---|
| 来源与身份 | 文件摘要匹配；股票日期键唯一；四分区行数、旧股票元数据和面板地址一致 |
| 标签日期 | 训练与验证选择记录满足收益实现日期边界；排除记录可以追溯 |
| 当日因子 | 完整日期有效股票集合及十个公式可由真实数据独立复算；原始因子计算只读取规定字段 |
| 时间可用性 | 对真实日期的原始因子执行输入前缀重算，已计算日期结果保持一致 |
| 参数估计 | 与旧 `train_fit` 的 `sample_eligible=1` 逐条身份相同；四个连续列在填补后计算分位边界；全部参数独立复算一致 |
| 处理范围 | 有效区间标记与原文件相同；测试全部处理；范围外的原始值和缺失位置保持一致 |
| 存储与输入 | 每个地址恰好写入一次；前 27 通道与旧读取器逐元素一致；四分区全部合格窗口的 37 通道输入有限 |
| 实验可比性 | 四组使用相同训练、验证、本地评价样本键；相同种子和周期的日期及批次键摘要相同 |
| 文件版本 | 正式目录重新打开后的数组、摘要和样本数量均与核验阶段一致 |

因子公式采用 `float64` 独立复算，要求 `rtol=1e-10, atol=1e-12`；新通道写入后的有限值比较要求 `rtol=1e-6, atol=1e-7`；旧 27 通道要求逐元素完全相同。核验覆盖训练各年首个、中间和最后有效日期，以及验证、留出、测试的首末有效日期；窗口和有限性检查遍历全部合格记录。详细检查编号沿用数据预处理方案中的 P01—P16。

现有官方测试面板有 1,599,600 条记录，原有合格序列有 1,597,202 条。报告分别给出合格记录输入完整性和官方测试全集覆盖率，列出两者相差记录的股票日期键。数据验收通过表示四组实验可在共同合格样本上读取一致输入；比赛提交的全集覆盖另按实际缺失键核验。
