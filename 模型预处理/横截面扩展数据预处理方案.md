## 5. 共同样本与标签时间规则

### 5.1 日期含义

`target_date=t` 是输入窗口末端日期；`y_ret_1d` 是该记录提供的下一交易日收益标签；`label_realization_date` 是该标签对应收益实现的日期。

根据原始数据中的真实交易日期构造市场交易日序列，将每个目标日期映射到下一交易日。跨年日期连续处理；股票缺失行情时，映射仍按市场交易日期推进。

实施时核对赛题说明中的收益计算口径、价格口径和单位，并用相邻交易日价格有效的真实记录检查标签的日期对应关系。标签保留数据提供值。无法解释的口径差异直接使标签核验失败。

### 5.2 最终资格

| 标记 | 定义 |
|---|---|
| `sample_eligible` | 继承原有预处理样本资格 |
| `inside_valid_interval` | 继承原有标准化文件中的有效区间标记 |
| `preprocess_fit_eligible` | `source_split=train_fit` 且原有 `sample_eligible=1`，用于新增特征参数估计 |
| `prediction_eligible` | 保留现有序列资格，用于规定允许读取的模型窗口 |
| `training_eligible` | `train_fit` 内原有序列合格、标签有限、实现日期已知且不晚于 2022 年最后交易日 |
| `selection_eligible` | `validation` 内原有序列合格、收益实现日期位于 2023 年验证范围 |

非对应分区的 `preprocess_fit_eligible`、`training_eligible`、`selection_eligible` 设为零。本地留出集和官方测试集沿用既有预测资格。

所有原始索引记录保留，新字段写入独立文件。边界排除清单保存股票、目标日期、收益实现日期、旧资格、新资格和排除原因，例如 `label_after_train_end`、`label_outside_validation`、`label_date_unknown`。

四组实验引用相同的最终索引版本。新增因子的缺失通过规定参数处理，扩展输入组的样本键与原有输入组一致。

### 5.3 样本范围说明

既有带标签样本包含历史有效区间等资格限制，本轮继承该规则并记录其适用范围。原有 27 通道复用已经保存的训练处理结果；新增十通道的参数使用原有 `train_fit` 中 `sample_eligible=1` 的记录拟合。标签实现日期检查用于确定训练和验证选择资格，参数估计样本保持原有定义。

横截面统计的股票集合在第 6 节单独定义，集合成员只由当日行情标记与当前源因子决定。

## 6. 十个原始新增因子

### 6.1 允许读取的计算字段

```text
ts_code, trade_date, missing_price_volume,
ret_1d, mom_5d, mom_20d, volatility_5d, amount_shock_5d, intraday_ret
```

生成函数采用上述字段白名单。标签、训练资格和未来有效区间信息均不进入该函数的输入。

源因子由[现有因子生成代码](E:/ChatGPT/ChatGPT_Project/深圳金融比赛赛题五/generate_factors.py)提供。源数据保存精度为 `float32`，横截面计算转为 `float64`；该转换提高后续统计运算精度，原始保存精度记录在审计中。

### 6.2 完整日期组织

源文件按股票组织，读取批次上限为 200,000 行。使用 PyArrow 将指定字段写入临时的来源与年份分区。全部记录完成整理后，以年度为单位读取、按交易日期分组，每次计算一个完整交易日。

同一交易日存在多个来源文件时，汇集全部当日记录并检查股票代码唯一。任何重复股票与日期键使生成终止。

原始因子输出保存 `raw_source`、`raw_source_row_index`、`ts_code`、`trade_date` 和十个特征。原始来源行号按原 Parquet 行序计数；分区索引中的 `source_row_index` 按标准化分区行序计数，两者通过股票与日期建立映射。

### 6.3 有效集合

对日期 t 和源因子 f：

\[
U_t^{(f)}=\{i:missing\_price\_volume_{i,t}=0,\ f_{i,t}\text{为有限值}\}.
\]

每个源因子采用自己的有效集合。当日涨停股票只要满足上述条件就参与统计。标签缺失的股票只要满足上述条件，同样参与统计。

源因子非有限值的数量按 NaN、正无穷和负无穷分别记录，计算时只使用有限值。身份字段、行情缺失标记和日期格式无效时直接终止。

### 6.4 固定列顺序与公式

原有特征顺序从旧元数据读取，新增字段按下表顺序追加。

| 通道 | 字段 | 计算方式 |
|---:|---|---|
| 28 | `csrank_mom_5d` | `mom_5d` 的当日升序平均名次比例 |
| 29 | `csrank_mom_20d` | `mom_20d` 的当日升序平均名次比例 |
| 30 | `csrank_volatility_5d` | `volatility_5d` 的当日升序平均名次比例 |
| 31 | `csrank_amount_shock_5d` | `amount_shock_5d` 的当日升序平均名次比例 |
| 32 | `csrank_intraday_ret` | `intraday_ret` 的当日升序平均名次比例 |
| 33 | `excess_ret_1d` | 个股收益减当日有效收益中位数 |
| 34 | `excess_mom_5d` | 个股五日动量减当日有效五日动量中位数 |
| 35 | `market_mean_ret_1d` | 当日有效一日收益均值 |
| 36 | `market_breadth_1d` | 当日有效一日收益严格大于零的比例 |
| 37 | `market_dispersion_1d` | 当日有效一日收益总体标准差，`ddof=0` |

排名比例：

\[
q_{i,t}=\frac{rank(f_{i,t})-1}{N_t^{(f)}-1},\qquad N_t^{(f)}\ge2.
\]

并列值使用平均名次。有效股票数量为 1 时，排名比例为 0.5；数量为零时保留缺失。个股未进入有效集合时，该股票的相应排名和相对收益保持缺失。

三个市场字段使用 `ret_1d` 的有效集合，按日期广播至全部当日来源记录。上涨比例的分母包含零收益股票，零收益不计入上涨数量。有效集合为空时，三个字段均缺失；仅一支有效股票时，市场离散度为零。

源字段 `volatility_5d` 保持已有五日收益样本标准差定义，`ddof=1`。`amount_shock_5d` 保持当天 `log1p(amount)` 减此前四日平均 `log1p(amount)` 的定义。

### 6.5 日期统计输出

逐日期、逐源因子保存：来源记录数、有效数量、缺失数量、非有限值数量、并列比例，以及涉及的中位数、均值和标准差。统计使用的集合数量作为独立审计字段保存。

历史窗口中的每个日期使用该日期自身的完整横截面结果。验证、留出和测试日期均可使用各自当天已知行情计算横截面统计。

## 7. 缺失值与尺度处理

### 7.1 参数来源

从共同索引中选择 `preprocess_fit_eligible=1` 的记录，即原有 `train_fit` 中 `sample_eligible=1` 的记录，通过股票与日期关联新增原始特征。每条记录等权计入一次。20 日窗口重叠产生的重复读取不会增加参数估计中的记录权重。

参数估计的股票与日期键必须与原有步骤 3—5 的参数估计样本完全相同。原有记录数量为 4,514,536，验收同时核验数量、逐条身份和排序后的键摘要。原有 `sample_eligible` 包含标签可用性条件，沿用该标记的参数估计样本具有同样的限制。第 6 节的原始因子生成独立使用行情字段白名单。

三个市场字段在同日不同股票上取值相同，参数估计仍按训练股票记录等权执行。验证、留出和测试使用固定训练参数。

### 7.2 六个有界特征

五个 `csrank_` 字段与 `market_breadth_1d`：

1. 检查所有有限原始值位于 [0,1]。
2. 用参数估计样本中的有限原始值估计中位数。
3. 在第 7.5 节规定的处理范围内填补缺失并执行 `2×value−1`，得到 [-1,1] 范围的模型输入。

这六个字段采用有界特征专用转换，省略分位截断和均值标准差缩放。参数文件保存训练中位数和转换方式；参数估计样本与允许处理范围沿用原有规则。

### 7.3 四个连续特征

`excess_ret_1d`、`excess_mom_5d`、`market_mean_ret_1d`、`market_dispersion_1d`：

1. 使用参数估计样本中的有限原始值估计中位数。
2. 使用该中位数填补参数估计样本中的缺失值。
3. 在填补后的参数估计样本上计算 0.5% 和 99.5% 分位边界，固定线性插值，再按边界截断。
4. 在填补且截断后的参数估计样本上计算均值和标准差，`ddof=0`。
5. 在第 7.5 节规定的处理范围内，使用固定参数依次填补、截断和标准化：`(value−mean)/std`。

分位数按特征逐列计算，使用填补后全部参数估计记录的精确分位数。计算期间只加载当前特征的参数估计值及必要身份信息。连续特征的参数来源、处理顺序和处理范围与原有步骤 3—5 保持一致。

### 7.4 参数有效性与审计

训练来源全部缺失、填补值非有限、截断边界非法、处理后标准差为零时，停止构建对应产物。输出记录以下内容：

- 每个参数对应的 `preprocess_fit_eligible` 样本键摘要、原有参数估计样本键摘要和原始特征摘要。
- 参数估计日期范围、目标记录数、有效值数和缺失数。
- 中位数、截断边界、均值、标准差和计算精度。
- 各分区填补数量、上下边界截断数量及比例。
- 变换前后分布统计与非有限值数量。

### 7.5 允许处理的记录范围

填补、截断及尺度转换统一使用 `inside_valid_interval=1` 或 `source_split=competition_test` 作为处理条件。训练、验证和本地留出分区直接继承原有 `inside_valid_interval` 标记；官方测试分区处理全部记录。有效区间标记从原有标准化文件按股票与日期关联读取。

允许处理范围之外保留新增原始特征值及缺失状态。十通道存储写入全部面板记录，有限性验收覆盖全部合格模型窗口。审计分别记录允许处理和保留原值的数量，并检查范围外记录的数值及缺失位置保持一致。

## 8. 面板位置与特征存储

### 8.1 股票地址

复用旧股票元数据中的 `stock_id`、`feature_offset` 和 `stock_length`。对股票内行号 k，存储地址为：

\[
address=feature\_offset+k.
\]

面板位置表通过四个旧序列索引建立，至少包含：`source_split`、`source_row_index`、`panel_row_id`、`ts_code`、`trade_date`、`stock_id`、`target_stock_row_number` 和 `store_row_index`。

`panel_row_id` 用作身份审计；实际读写地址使用 `store_row_index`。来源文件行号、股票内行号和存储地址分别核验。

### 8.2 完整写入

新增存储形状为 `(9499950,10)`，`float32` 原始容量为 379,998,000 字节，约 362.4 MiB。实际形状从旧元数据推导，要求与输入清单匹配。

按股票与日期一对一关联原始新增因子和面板位置，执行第 7 节变换后写入地址。覆盖所有原面板记录，包括历史窗口尚不足 20 日的记录。

维护一个覆盖全部地址的布尔标记，逐批检查地址越界、批次内部重复和既有写入重复。完成后要求每个地址恰好写入一次，全部合格窗口中的新增输入有限；允许处理范围之外的缺失按第 7.5 节保留。

`float64` 转为 `float32` 时，对有限值记录最大绝对误差和相对误差，并核验缺失位置保持一致、有限值转换后仍有限。写入完成后刷新并关闭映射，再以只读方式重新打开进行核验。

### 8.3 原有通道复用

旧 `特征存储.dat` 以只读模式访问。扩展输入读取同一组历史地址的 27 通道和十通道，按最后一个维度拼接。

前 27 通道的列顺序、数值和既有缩放参数保持一致。需要回溯处理方法时，引用原有预处理记录；新增处理参数保存在独立文件中。

## 9. 样本索引与日期索引

### 9.1 样本字段

生成 `样本索引_{split}.parquet`，保留全部来源记录，按 `target_date、ts_code` 排序。

| 字段 | 类型与作用 |
|---|---|
| `source_split`、`source_row_index` | 来源分区和分区内 int64 行号 |
| `panel_row_id` | int64 面板身份 |
| `ts_code`、`target_date` | 股票代码和 int64 日期 |
| `stock_id`、`feature_offset` | int32 股票编号和 int64 存储偏移 |
| `target_stock_row_number` | int64 股票内目标行号 |
| `window_start_stock_row_number` | 可空 int64 窗口起点 |
| `sample_eligible`、`inside_valid_interval` | int8 原有样本资格和有效区间标记 |
| `preprocess_fit_eligible` | int8 新增特征参数估计资格 |
| `prediction_eligible` | int8 既有输入资格 |
| `training_eligible`、`selection_eligible` | int8 训练与验证选择资格 |
| `label_realization_date` | 带标签分区的可空 int64 收益实现日期 |
| `y_ret_1d` | 带标签分区的 float32 收益标签 |
| `flag_limit_up` | 目标日期涨停字段，float32 |

官方测试索引省略 `y_ret_1d` 和 `label_realization_date`。所有必需身份字段和合格窗口位置有效，窗口起点加 19 应当等于目标股票内行号。

### 9.2 训练位置与日期区间

在排序后的训练样本索引中提取 `training_eligible=1` 的文件行号，生成 `训练位置_train_fit.parquet`。其字段为 `position` 和 `index_row_position`，均为 int64。

生成 `日期索引_train_fit.parquet`，保存 `target_date`、`start_position`、`end_position_exclusive` 和 `eligible_count`。区间指向训练位置表，终点采用右侧不包含的规则。

读取器按日期区间得到训练位置，再找到对应样本索引记录。核验日期区间连续覆盖训练位置表，数量之和等于最终训练记录数。

## 10. 读取接口与同日批次

### 10.1 数据读取

拟实现 `模型训练/cross_section_input.py`，由预处理任务交付其 NumPy 数据接口：

```text
CrossSectionInputReader(base_metadata_path, extra_metadata_path,
                        index_path, feature_mode)
read_batch(index_positions)
iter_inference_batches(batch_size=4096)
SameDateBatchSampler(index, seed, epoch, max_batch_size=512)
```

`feature_mode=base27` 返回 `(B,20,27)`，`feature_mode=extended37` 返回 `(B,20,37)`。批次包含 `x`、股票代码、目标日期、面板身份和输入资格；带标签分区增加 `y`。

窗口只读取同一股票的连续 20 条历史面板记录，日期严格递增，末端等于目标日期。前一分区的更早行情可以进入后续分区窗口。

### 10.2 同日采样

按种子、周期和固定用途编号初始化独立随机发生器，排列日期，再排列当日股票。日期内部以 `ceil(N/512)` 确定批次数量，使用均衡划分形成最多 512 条的批次。

每条最终训练记录在一个周期内恰好出现一次。采样随机状态与模型随机状态分开，实验组、输入通道和排序权重不参与采样随机种子的构造。

预处理核验使用种子 42、43、44，逐个遍历一个完整周期的索引；另外检查下一周期的可重复生成。27 和 37 通道模式使用相同批次位置与键摘要。

同日股票之间的排序损失由训练任务计算。当前数据交付提供真实标签、日期和批次身份。

## 11. 配置、文件版本与运行安全

### 11.1 独立预处理配置

拟创建 `模型预处理/横截面扩展数据预处理配置.json`，包含 `project_root`、输入路径、输出根目录、日期范围、十列固定顺序、有效集合规则、资格规则、参数估计样本规则、允许处理范围、参数处理顺序、批量上限、采样核验种子和数值容差。参数估计资格与模型训练资格分别配置和核验。

该配置负责数据生成。后续正式实验配置通过数据交付清单引用已验收产物，读取并核对十列顺序、20 日窗口、样本摘要和处理参数摘要。

`build_id` 由构建时间与配置摘要组成。数据读取器要求传入显式路径，配置加载和路径检查采用快速失败方式。

### 11.2 文件状态

文件先写入项目目录下 `tmp/横截面排序实验/{build_id}`，该目录已由 `.gitignore` 的 `tmp/` 规则覆盖。使用成熟库读写 Parquet 和 JSON。

全部构建完成后，在临时目录执行核验。确认文件关闭后，将产物转入新的正式构建目录，重新解析正式文件位置和校验摘要，最后写入 `数据交付清单.json`。

清单采用 `status=complete`、`data_verified=true` 表示数据构建完成且通过核验。训练任务另外执行模型与 CUDA 检查。未完成构建使用不同状态，读取器拒绝作为正式训练输入。

### 11.3 内存与异常处理

输入按 200,000 行读取，完整日期统计按年度组织，精确分位数按单个特征处理，模型窗口按批读取。记录各步骤用时、处理行数和峰值内存。

重复键、映射遗漏、标签日期无法解释、无效参数、合格窗口出现非有限输入或写入不完整时，程序在发生位置终止。完整原始输入只读保留；重新执行创建新构建身份。

## 12. 真实数据核验清单

公式复算采用训练每年首个、中间和最后有效日期，并覆盖验证、留出、测试的首末有效日期。每个选中日期读取完整股票集合。窗口核验覆盖分区边界附近的真实股票和日期。

| 编号 | 核验内容 | 通过条件 |
|---|---|---|
| P01 | 来源结构、键和文件摘要 | 字段符合配置，键唯一，记录数量和文件身份一致 |
| P02 | 标签实现日期 | 训练和验证选择记录满足边界，排除清单可追溯 |
| P03 | 横截面有效集合 | 每个源因子的有效股票身份和数量与独立复算相同 |
| P04 | 十个原始特征 | float64 复算满足 `rtol=1e-10, atol=1e-12` |
| P05 | 标签隔离 | 生成函数只读取白名单，真实标签缺失且行情有效的记录参与对应统计 |
| P06 | 时间可用性 | 截至真实日期的输入前缀重算，已有日期的原始因子保持一致 |
| P07 | 训练处理参数 | 参数估计键与原有 `train_fit` 中 `sample_eligible=1` 的键完全相同；填补后估计分位边界，逐列复算参数一致 |
| P08 | 存储地址与写入 | 地址完整且唯一，股票与日期对应，文件字节数正确 |
| P09 | 历史窗口 | 单一股票、20 条记录、日期递增、末端等于目标日期 |
| P10 | 原有 27 通道 | 与旧读取器的相同样本逐元素完全相等 |
| P11 | 新增十通道 | 处理条件与原有规则一致；范围内变换满足 `rtol=1e-6, atol=1e-7`，范围外保留原值并核验转换误差与缺失位置 |
| P12 | 全量合格输入 | 四分区全部合格窗口形状正确、输入有限；测试批次无标签 |
| P13 | 同日采样 | 全部批次同日，最大 512 条，每个目标记录恰好出现一次 |
| P14 | 样本与批次一致性 | 四组共享资格键，27/37 模式同种子、同周期批次摘要相同 |
| P15 | 重新打开产物 | 关闭并重开正式存储后，窗口结果与核验时一致 |
| P16 | 测试覆盖与交付清单 | 合格键数量匹配，缺失键可追溯，文件摘要和完成状态齐全 |

旧读取器使用 `as_torch=False` 进行 P10 检查。全量有限性核验通过分批遍历完成，真实数据中的并列值、空集合等自然边界情况分别记录覆盖范围。

预处理报告只填写实际执行的检查。全部必需检查通过后，生成数据完成状态。
